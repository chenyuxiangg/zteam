# Gomoku 用户指南（v0.4.0）

## 1. 简介
Gomoku 是一个运行于 **Linux 终端**的五子棋人机对战游戏（Python 实现）：你在终端里与电脑对弈，棋盘以彩色渲染，支持三种 AI 难度与可选的连珠禁手规则。它解决的是"在服务器/SSH 环境里也能开箱即玩一局像样的五子棋"的问题——无需图形界面，纯终端即可运行。

核心特性：
- 标准五子棋规则：横/竖/斜任一连成五子即胜（长连也判胜）；
- 棋盘规格：15×15（默认）或 13×13；
- AI 三档：弱（合法落子不主动送死）/ 中（识别并封堵双三/冲四威胁）/ 强（Alpha-Beta 深度搜索 + 主动进攻）；
- 禁手开关（连珠规则）：开启后黑方受双三/双四/长连禁手约束，与成五同时发生时判黑胜；
- 坐标双格式输入：`A8`（字母+数字）或 `8,8`（纯数字）；
- 干净退出：Ctrl+C / Ctrl+D / 输入 `quit` 均可安全退出，终端状态自动恢复。

## 2. 安装
### 环境要求
- Linux（任意发行版），Python ≥ 3.10（3.10/3.11 已验证）；
- 终端 ≥ 60 列 × 24 行（15×15 棋盘完整显示；13×13 需 ≥50×20）；
- 建议硬件基线（强档 AI 响应 ≤2s）：x86-64 四核及以上、≥8GB 内存。

### 安装步骤（三种方式任选）
```bash
# 方式 A：从发布包安装（推荐）
tar xzf gomoku-v0.4.0.tar.gz
cd gomoku-v0.4.0
pip install .            # 自动安装唯一运行时依赖 rich>=13.0

# 方式 B：源码目录可编辑安装（开发用，含测试依赖）
cd gomoku-v0.4.0
pip install -e .[dev]

# 方式 C：不安装，直接运行
cd gomoku-v0.4.0
PYTHONPATH=. python3 -m gomoku
```

### 校验安装包完整性（可选）
```bash
# 在包含 SHA256SUMS 的目录执行
sha256sum -c SHA256SUMS
```

## 3. 快速开始
```bash
gomoku
```
出现棋盘后直接输入坐标落子即可，例如输入 `H8` 回车（中央点）。人类默认执黑先行，AI 自动应对。界面顶部状态栏显示当前轮到谁与上一步坐标，棋盘上上一步位置以特殊标记显示。想换一局配置？试试：

```bash
gomoku --size 13 --difficulty strong --forbidden on
```

### 第一个完整对局示例
```
$ gomoku --size 13 --difficulty weak
Turn: Black  Game started.  Enter move (e.g. A8 or 8,8), or 'quit':
your move > H8          ← 人类落子
your move > 8,8         ← 数字格式同样可用
...
```
每步输入合法坐标（如 `A1`/`a1`/`1,1`）落子；五连时界面显示胜方横幅；对局结束后可输入 `y` 立即重开或 `n` 退出。

## 4. 使用说明
### 4.1 命令行参数
| 参数 | 取值 | 默认 | 说明 |
|------|------|------|------|
| `--size` | `13`, `15` | `15` | 棋盘边长 |
| `--difficulty` | `weak`, `medium`, `strong` | `medium` | AI 难度 |
| `--forbidden` | `on`, `off` | `off` | 连珠禁手开关（仅约束黑方） |
| `--human` | `black`, `white` | `black` | 人类执子方 |
| `--debug-timing` | — | 关 | 每次渲染耗时输出到 stderr（性能验证用） |
| `--version` | — | — | 打印版本 |
| `--help` | — | — | 打印帮助 |

### 4.2 输入格式
- 字母格式：`A8` = 第 A 列第 8 行（不区分大小写，`a8` 等价）；13×13 棋盘合法列 A–M，15×15 为 A–O；
- 数字格式：`8,8` = 第 8 列第 8 行（两个数字均为 1 起始）；
- 非法输入（越界/已占用/格式错误）会给出具体原因提示并允许重输，不会崩溃。

### 4.3 对局控制
- 随时输入 `quit`、`exit` 或 `q` 退出；Ctrl+C / Ctrl+D 同样安全退出；
- 一局结束后按提示选择重开（沿用当前配置）或退出；
- 禁手开启时，若你执黑走出双三/双四/长连，程序判你负（白胜）；同时成五则判黑胜（连珠规则）。

### 4.4 AI 行为说明
- 弱档：邻域内合法随机落子，带"不主动送死"过滤——适合新手熟悉规则；
- 中档：模式评估 + 一步威胁封堵，能识别并阻止你的冲四/活三；
- 强档：Alpha-Beta 搜索（迭代加深 1~4 层）+ 候选剪枝 + 1.5s 时间预算，在封堵基础上主动构造冲四/活三进攻；禁手开启且 AI 执黑时，AI 会预过滤禁手点。

## 5. 常见问题（FAQ）
| 症状 | 原因与解决 |
|------|-----------|
| `ModuleNotFoundError: No module named 'rich'` | 未安装依赖：`pip install rich` 或重跑 `pip install .` |
| `No module named 'gomoku'` 运行 `gomoku` 命令报错 | 包未安装成功：重跑 `pip install -e .` |
| 黑白子看起来一样 | 终端无彩色：设置 `TERM=xterm-256color` 或 `NO_COLOR=` 后重启；无彩色环境自动降级为 ●/○ 字符 |
| 提示 "terminal too small" | 终端小于 60×24（13×13 需 50×20）：放大窗口后回车继续 |
| 强档 AI 落子超过 2 秒 | 硬件低于建议基线：属预期，耗时仅记录不视为故障（NFR 参考基线声明） |
| 想玩禁手规则但不懂规则 | 黑方禁止一步同时形成两个活三（双三）、两个四（双四）或六连以上（长连）；`--forbidden on` 开启 |
| 自检命令怎么跑 | `python3 -m gomoku.forbidden_cases`（禁手 24 例）、`python3 -m gomoku.ai_self_check`（AI 能力 4 项）、`bash scripts/smoke.sh`（端到端冒烟） |

## 6. 卸载
```bash
pip uninstall gomoku
```
- 程序为纯本地单机应用，无用户数据文件、无配置残留、无系统服务，卸载后无任何残留；
- 如曾使用可编辑安装（`pip install -e .`），同样执行上述命令；源码目录删除即可（`rm -rf gomoku-v0.4.0`）；
- 如卸载后想恢复：重新按第 2 节安装即可。
