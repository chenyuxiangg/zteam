## 4. 安装与使用
- 安装：
  ```bash
  tar xzf gomoku-v0.4.0.tar.gz && cd gomoku-v0.4.0
  pip install .            # 自动安装依赖 rich>=13.0；开发/测试用 pip install -e .[dev]
  # 校验完整性：sha256sum -c SHA256SUMS（在 release 目录）
  ```
- 运行：
  ```bash
  gomoku                              # 默认 15×15、中档 AI、无禁手
  gomoku --size 13 --difficulty strong
  gomoku --forbidden on --human white  # 连珠禁手 + 人类执白
  # 不安装直接跑：PYTHONPATH=. python3 -m gomoku
  ```
- 卸载：`pip uninstall gomoku`（纯本地安装，无残留数据文件；详细见用户指南.md）

## 5. 已知限制与风险
- **测试脆弱性（本次自检发现）**：全量 pytest 运行曾出现 1 例偶发失败 `test_human_wins_with_known_sequence`（test_integration）——该用例假设 weak AI 不封堵人类固定冲四序列，而 weak 档为合法随机落子，AI 随机挡线时用例即失败；单独复跑 3/3 通过，非产品缺陷。quality 门禁运行（144/144）与 test 评审运行（145/145）均全绿。建议后续迭代将弱档随机种子固定或改为构造性断言。
- **产品既有限制（README §9 登记）**：不实现联机/双人、悔棋、棋谱/开局库/残局库、连珠完整开局规则（五手交换等）、Gomocup 竞赛级棋力；AI 评估函数四方向求和存在有意 over-counting（评分表已按相对排序调参）；跳四边界形态（B.BBB/BBB.B/XX.XX 等）依赖反向定义扫描+短线兜底，近边界候选端有分类兜底逻辑；15×15 棋盘需 ≥60 列 ×24 行终端（过小会提示调整）。
- **性能基线**：NFR-01（强档中盘 ≤2s）以 x86-64 四核+/≥8GB/Python 3.10+ 为参考基线（plan H10），低于基线硬件实测值仅记录不视为不达标；本次自检实测 1503ms。
- **评审遗留**：quality/security 门禁合计 12 项建议级意见（docstring、冗余分支、README 措辞、counter-threat 门槛收紧、draw 端到端断言等），均不阻塞发布，留待后续迭代。
