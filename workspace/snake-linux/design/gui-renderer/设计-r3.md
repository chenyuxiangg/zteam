### 1.2 迭代 3 增量：Skin 新字段

```python
from dataclasses import dataclass, field

@dataclass(frozen=True)
class Skin:
    # 迭代 1 字段（保留）
    name: str
    background: Color
    grid_line: Color
    snake_head: Color
    snake_body: Color
    food: Color
    food_outline: Color
    hud_text: Color
    hud_accent: Color
    # 迭代 3 新增（默认值 → 迭代 1 老 Skin 自动兼容）
    hud_shadow: Color = field(default_factory=lambda: Color(0, 0, 0))  # HUD 文本阴影色（深色背景时增强可读性）
    cell_gap: int = 1                                                 # 单格间隙像素（0=无缝；经典=1，深色=2，色盲=1）
    food_pattern: str = "solid"                                       # 食物形状辅助辨识：solid / ringed / checkered
    snake_pattern: str = "solid"                                      # 蛇身纹理辅助辨识：solid / striped
```

> **统一写法（r2 P3-3 保留）**：所有 Color 字段默认值一律 `field(default_factory=lambda: Color(...))`，避免「直接默认值 vs factory」两种写法并存。

**字段默认值兼容矩阵（r2 P3-1 保留）**：

| 皮肤 | cell_gap | food_pattern | snake_pattern | hud_shadow |
|------|---------:|--------------|---------------|-----------:|
| classic | 1 | solid | solid | (0,0,0) |
| dark | 2 | ringed | solid | (0,0,0) |
| colorblind_friendly | 1 | checkered | striped | (255,255,255) |

> **色盲友好设计**：FR-10 要求「不以颜色为唯一区分手段」。三重视觉冗余：
> 1. `cell_gap` 间隙拉开轮廓辨识；
> 2. `food_pattern` 食物用 **checkered（棋盘格）** 纹理而非纯红；
> 3. `snake_pattern` 蛇身用 **striped（横条纹）** 渐变；
> 加上 **out-of-band 形状差异**（食物本身非正方形，本实现层将食物渲染为略小一圈 + 描边）。

### 1.5 插值动画数据结构（**修订 P2-2：删除 InterpolatedCell**）

```python
@dataclass(frozen=True)
class InterpolationState:
    """一次 render 的插值上下文（FO 从主循环传入；renderer 只读）。

    prev_snake_body / prev_food 表示**上一节拍**（即 game-core step 推进前）的快照
    蛇身与食物网格坐标。FO 必须在 step() 之前缓存 prev_*；step 之后 prev_* 不再更新，
    直到下一个节拍到来再以新位置作为下一段插值的 prev_*。

    **prev_food 为 None 的语义（修订 P2-1）**：表示该节拍食物不应插值（如吃食节拍
    食物从被吃位置直接出现于新随机位置，相距 >1 格时视觉上不应"滑行"过渡），
    renderer 渲染时直接画 snap.food 当前坐标（瞬移）。
    """
    alpha: float                                       # 0.0~1.0；0=完全上一节拍，1.0=完全当前帧
    prev_snake_body: Tuple[Tuple[int, int], ...]       # **上一节拍**（step 前）蛇身网格坐标
    prev_food: Optional[Tuple[int, int]] = None        # **上一节拍**（step 前）食物网格坐标；None=食物不插值
```

> **修订 P2-2**：删除 r2 定义的 `InterpolatedCell`（无消费点，§4.4/§8 均未使用，仅 UT 在自检）。同时从 §3.3 公开 API 清单、§7.6 用例清单移除。本类型曾在迭代 1 评审中触发"Rect 无消费点"覆辙，本次彻底清理。

> **修订 P2-1（食物插值开关语义）**：
> 1. `InterpolationState.prev_food=None` → renderer 渲染食物时**不插值**（直接画 snap.food 当前坐标），用于**吃食节拍**——被吃的食物已消失，新食物已生成，相距可能 >1 格，不应视觉"滑行"过渡；
> 2. `prev_food=(x, y)` 且 `snap.food=(x', y')` 距离 >1 格时 → renderer 检测后**自动跳过插值**（视觉语义错误兜底），仍按 snap.food 当前坐标渲染；
> 3. 距离 ≤1 格的常规节拍 → 按 alpha 插值绘制；
> 4. game-app 在节拍到达时判断：若 `prev_snap.food != snap.food`（吃食节拍），传 `prev_food=None`；否则传 `prev_food=prev_snap.food` 网格坐标。

> **设计决策**：renderer **不内置**「上一节拍缓存」——插值状态由 game-app 在主循环维护（每节拍推进时 game-core snapshot 给出新坐标，旧坐标就是 InterpolationState.prev_*）。这是职责边界：renderer 只读插值输入、不持有游戏状态。

> **修订 P1-1（r2 已落地，r3 保留）**：`prev_*` 明确为**上一节拍（step 前）**快照，不是 step 后的新位置；FO 在主循环伪代码中必须严格按 §8 顺序：step **之前**缓存 prev_*，step **之后**才用 prev_* 与新 snap 一起构造 interp。

> **接口影响**：`render(snapshot, hud)` 签名不变，新增 `render(snapshot, hud, *, interp=None)` 可选参数。interp 为 None 时按 alpha=1.0 渲染（即无插值，瞬移），保持迭代 1 调用契约 100% 兼容。

### 2.2 插值数据流（修订 P1-1 + P2-1）

```
game-app 主循环（节拍推进 + 插值缓存时序）：
  初始化：
    prev_snap = state.snapshot()             # 缓存初始快照
    prev_body = tuple((p.x, p.y) for p in prev_snap.snake_body)
    prev_food_grid = (prev_snap.food.x, prev_snap.food.y)
    ticks_in_step = 0

  帧循环：
    if ticks_in_step >= state.snapshot().tick_ms // 16:
        # —— 节拍到达：先缓存旧位置作为下一段插值的 prev_*，再 step ——
        prev_snap = state.snapshot()         # ✅ step 前：旧位置 A
        state = state.step()                 # snapshot 变新位置 B
        prev_body = tuple((p.x, p.y) for p in prev_snap.snake_body)
        # 修订 P2-1：吃食节拍 prev_food 传 None（食物不插值）
        if prev_snap.food == state.snapshot().food:
            prev_food_grid = (prev_snap.food.x, prev_snap.food.y)  # 同位置 → 可插值
        else:
            prev_food_grid = None                                  # 吃食 → 食物不插值
        ticks_in_step = 0

    snap = state.snapshot()                  # 当前帧的 B 位置
    alpha = ticks_in_step / (snap.tick_ms // 16)
    interp = InterpolationState(
        alpha=alpha,
        prev_snake_body=prev_body,            # A
        prev_food=prev_food_grid,             # A 或 None（吃食节拍）
    )
    render(snap, hud, interp=interp)         # 蛇从 A → B 平滑插值；食物按 prev_food 决定
```

**关键约束（修订 P1-1 + P2-1）**：

1. **renderer 不缓存 prev 状态**；game-app 在节拍推进时主动维护 InterpolationState.prev_*。
2. **缓存时机**：必须在 `state.step()` **之前**读取 `state.snapshot()` 作为 prev_*；step 后 snapshot 已变为新位置，缓存 step 后的快照会让 prev == current，插值恒等于同位置渲染（FR-07 验收必失败）。
3. **吃食节拍食物不插值**（修订 P2-1）：食物坐标变化时（吃食），`prev_food=None`；食物坐标未变时（未吃食），`prev_food` 网格坐标。renderer 内部再做距离兜底（>1 格自动跳过）。

**正确性推演**（tick_ms=160 → 10 帧/节拍）：

| 帧序号 | 节拍进度 | prev（缓存） | snap（当前） | alpha | 渲染位置 |
|-------|---------|--------------|--------------|-------|----------|
| 1 | 0/10 | A | A | 0.0 | A |
| 2 | 1/10 | A | A | 0.1 | A+0.1·(A-A)=A |
| ... | ... | A | A | ... | A |
| 10 | 9/10 | A | A | 0.9 | A |
| 11（节拍到达） | 先缓存 prev=A，再 step → snap=B | A | B | 0.0 | A |
| 12 | 1/10（新节拍） | A | B | 0.1 | A+0.1·(B-A) |
| ... | ... | A | B | ... | 从 A 平滑过渡到 B |
| 20 | 9/10 | A | B | 0.9 | A+0.9·(B-A)≈B |
| 21（下一节拍） | 先缓存 prev=B，再 step → snap=C | B | C | 0.0 | B |

蛇身从 A 逐步过渡到 B（帧 11~20，alpha 0→0.9），下一节拍继续从 B 过渡到 C。**FR-07「无整格跳变」验收达成**。

### 2.3 缩放数据流（修订 P2-1；常量引用修订 P1-2 → 迭代 1 既有常量）

```
用户拖动窗口 → pygame.WINDOWEVENT/RESIZED 事件 → game-app 回调
  → renderer.handle_resize(event.w, event.h)
  → renderer 内部：
      1. 校验类型（w/h 为正整数）
      2. 校验 w/h >= 最小可玩尺寸（MIN_PLAYABLE_W, MIN_PLAYABLE_H）→ 否则抛 RenderError
      3. 重算 cell_size = min((w - 2*PLAYFIELD_X)/grid_cols, (h - PLAYFIELD_Y - PLAYFIELD_X)/grid_rows)
         cell_size 下限 CELL_SIZE_MIN=8，上限不超过初始 cell_size 的 2 倍
      4. 字体按比例缩放（font_size = HUD_FONT_SIZE * cell_size / CELL_SIZE）
      5. self._cell_size = 新值
      6. 调用 pygame.display.set_mode((w, h), flags) 重建屏幕（保留 SCALED 标志）
  → 下一帧 render 用新 cell_size
```

> **最小可玩尺寸定义**：`MIN_PLAYABLE_W = GRID_COLS * CELL_SIZE_MIN + 2 * PLAYFIELD_X`、`MIN_PLAYABLE_H = GRID_ROWS * CELL_SIZE_MIN + PLAYFIELD_Y + PLAYFIELD_X`（取自迭代 1 `_min_window_size` 公式）。任一维度小于最小可玩尺寸 → 抛 `RenderError`，由 game-app 捕获并向用户呈现可读提示（NFR-03），符合 FR-09「小于最小尺寸时给出提示而非画面错乱」。

class RenderError(RuntimeError):

### 4.4 平滑插值动画实现（render.interp 分支）

**插值数学**（仅 x/y 二维坐标，z=0）：

```python
def _interpolate_position(prev: Tuple[int,int], current: Tuple[int,int], alpha: float) -> Tuple[float, float]:
    """线性插值：prev + alpha * (current - prev)。alpha=0→prev；alpha=1→current。"""
    px = prev[0] + alpha * (current[0] - prev[0])
    py = prev[1] + alpha * (current[1] - prev[1])
    return (px, py)


def _grid_distance(a: Tuple[int,int], b: Tuple[int,int]) -> int:
    """网格距离（max(|dx|, |dy|)，Chebyshev）。仅蛇身/食物单格场景。"""
    return max(abs(a[0] - b[0]), abs(a[1] - b[1]))
```

> **修订 P2-1**：renderer 内食物绘制前调用 `_grid_distance(prev_food, snap.food)`，距离 >1 格 → 自动跳过插值（按 snap.food 当前坐标渲染）。这是兜底——FO 即使忘了传 `prev_food=None`，视觉也不会出错（食物"瞬移"到正确位置）。

```python
def render(self, snapshot, hud, *, interp=None):
    # 修订 P3-2：未 init 时抛 RenderError（与迭代 1 assert 行为一致，但异常类型语义更明确）
    if self._screen is None:
        raise RenderError("render() 前必须 init()；未 init 时屏幕对象不存在")
    if snapshot is None: raise RenderError("snapshot 不能为 None")
    if not snapshot.snake_body: raise RenderError("snapshot.snake_body 不能为空")

    t0 = pygame.time.get_ticks()
    screen = self._screen
    screen.fill(self._skin.background)

    # 计算插值 alpha（默认 1.0 = 无插值）
    alpha = 1.0
    prev_body = None
    prev_food = None
    if interp is not None:
        alpha = max(0.0, min(1.0, interp.alpha))   # clip 越界
        prev_body = interp.prev_snake_body
        prev_food = interp.prev_food                # 可能为 None（修订 P2-1）

    # 蛇身绘制
    cell_draw = self._cell_size - self._skin.cell_gap
    for i, point in enumerate(snapshot.snake_body):
        cur = (point.x, point.y)
        if prev_body is not None and i < len(prev_body):
            cur = _interpolate_position(prev_body[i], cur, alpha)   # 浮点亚像素
        px, py = self._grid_to_pixel(cur)
        px_i, py_i = int(round(px)), int(round(py))
        color = self._skin.snake_head if i == 0 else self._skin.snake_body
        pygame.draw.rect(screen, color, (px_i, py_i, cell_draw, cell_draw))

    # 食物绘制（修订 P2-1：prev_food=None 或距离 >1 格 → 跳过插值）
    food_cur = (snapshot.food.x, snapshot.food.y)
    if prev_food is not None and _grid_distance(prev_food, food_cur) <= 1:
        food_cur = _interpolate_position(prev_food, food_cur, alpha)
    fpx, fpy = self._grid_to_pixel(food_cur)
    fpx_i, fpy_i = int(round(fpx)), int(round(fpy))
    self._draw_food(screen, fpx_i, fpy_i, cell_draw)  # 按 food_pattern 分发

    # HUD（修订 P1-1 + P1-2：5 段 × (阴影 blit + 主版 blit)，font.render 仍 5 次）
    self._draw_hud(hud)

    t1 = pygame.time.get_ticks()
    self._fps.samples.append(float(t1 - t0))

    HIGH_X = 200
    LENGTH_X = 400
    DIFF_X = 16

    surf_status = self._font.render(f"Status: {hud.status_label}", True, status_color)
    self._screen.blit(surf_status, (STATUS_X + SHADOW_OFFSET[0], HUD_SECOND_LINE_Y + SHADOW_OFFSET[1]))
    self._screen.blit(surf_status, (STATUS_X, HUD_SECOND_LINE_Y))
```

>

### 4.6 窗口等比缩放（handle_resize，修订 P2-1）

```python
def handle_resize(self, w: int, h: int) -> None:
    # 1. 类型校验
    if not isinstance(w, int) or not isinstance(h, int) or w <= 0 or h <= 0:
        raise RenderError(f"handle_resize 尺寸应正整数，收到 {(w, h)}")

    # 2. 最小可玩尺寸校验（r2 P2-1 保留：与 §5.5 鲁棒性表 + §7.5 断言一致 → 抛 RenderError）
    if w < MIN_PLAYABLE_W or h < MIN_PLAYABLE_H:
        raise RenderError(
            f"handle_resize 尺寸 {(w, h)} 小于最小可玩尺寸 "
            f"({MIN_PLAYABLE_W} x {MIN_PLAYABLE_H})；"
            f"FR-09 要求小于最小尺寸时给出提示，由 game-app 捕获后向用户呈现"
        )

    # 3. 计算新 cell_size：保持 grid_cols/rows 不变，等比缩放
    avail_w = w - 2 * PLAYFIELD_X
    avail_h = h - PLAYFIELD_Y - PLAYFIELD_X
    new_cell_w = avail_w // self._grid_cols
    new_cell_h = avail_h // self._grid_rows
    new_cell = min(new_cell_w, new_cell_h)
    new_cell = max(CELL_SIZE_MIN, min(new_cell, CELL_SIZE * 2))
    # 上限 2*DEFAULT 防止窗口极大时网格过大溢出；下限 MIN 防止过小无法辨识

    # 4. 字体按 cell_size 比例缩放（保证 HUD 文字大小与网格匹配）
    new_font_size = max(10, int(round(HUD_FONT_SIZE * new_cell / CELL_SIZE)))

    # 5. 重建屏幕（保留 SCALED 标志）
    if not self._initialized:
        raise RenderError("handle_resize 前必须 init()")
    flags = self._flags  # 保留 SCALED 标志
    self._screen = pygame.display.set_mode((w, h), flags)
    self._font = pygame.font.SysFont(HUD_FONT_NAME, new_font_size)

    # 6. 更新内部状态
    self._window_size = (w, h)
    self._cell_size = new_cell
```

> **职责**：handle_resize 由 game-app 在 pygame.WINDOWEVENT/RESIZED 事件回调中调用；renderer 不监听 pygame 事件（保持 renderer 纯渲染函数特性，事件循环在 game-app）。

### 4.7 高分屏清晰（enable_high_dpi）

pygame 2.x 的 `pygame.SCALED` 标志让 SDL 自动按显示器 DPR 放大窗口（HiDPI 清晰）；1.x 不支持（迭代 1 §6 资源评估已说明）。迭代 3 实装：

```python
def __init__(self, window_size, *, skin=None, vsync=True,
             cell_size=CELL_SIZE, grid_cols=GRID_COLS, grid_rows=GRID_ROWS,
             enable_high_dpi=True):
    # ... 既有校验 ...
    self._enable_high_dpi = enable_high_dpi

def init(self) -> None:
    if self._initialized: return
    pygame.init()
    pygame.font.init()
    flags = 0
    if self._enable_high_dpi:
        # pygame 2.x：pygame.SCALED = 0x40000000 等价（直接用常量）
        flags |= pygame.SCALED  # 若版本不支持会抛 AttributeError → UT 跳过此分支
    self._flags = flags
    self._screen = pygame.display.set_mode(self._window_size, flags)
    self._font = pygame.font.SysFont(HUD_FONT_NAME, HUD_FONT_SIZE)
    self._initialized = True
```

**兼容性**：pygame.SCALED 在 2.0+ 才有；UT 用 fake_pygame 注入时不需要关心真实标志值（fake 只记录 set_mode 调用），只需断言 set_mode 被传入非 0 flags（当 enable_high_dpi=True）。

## 8. 与 game-app 的对接契约（接口示意）

game-app 迭代 3 / 4 接入方式（伪代码，本模块设计不含 game-app 改动）。**修订 P1-2**：构造 GameState 改为 keyword 写法。**修订 P1-1**：prev 缓存在 step **之前**。**修订 P2-1**：吃食节拍 prev_food 传 None。

```python
from game_core import GameState, Difficulty, Snapshot
from platform_storage import HighScoreStore
from gui_renderer import (
    Renderer, HudData, InterpolationState, SKIN_REGISTRY,
)

highscore_store = HighScoreStore()
state = GameState(width=20, height=15, difficulty=Difficulty.MEDIUM)  # keyword 写法（修订 P1-2）
prev_snap = state.snapshot()       # 缓存初始快照作为 prev
prev_food_grid = (prev_snap.food.x, prev_snap.food.y)
prev_body = tuple((p.x, p.y) for p in prev_snap.snake_body)
ticks_in_step = 0                  # 当前节拍内已渲染帧数

with Renderer((640, 480), enable_high_dpi=True) as renderer:
    clock = pygame.time.Clock()
    running = True
    while running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT: running = False
            elif event.type == pygame.WINDOWEVENT and event.event == pygame.WINDOWEVENT_RESIZED:
                renderer.handle_resize(event.w, event.h)
            elif event.type == pygame.KEYDOWN and event.key == pygame.K_s:
                # 切皮肤（轮询三个）
                names = renderer.skin_names()
                idx = names.index(renderer.current_skin_name)
                renderer.set_skin(names[(idx + 1) % len(names)])

        # 节拍推进 + prev 缓存（修订 P1-1：step 前缓存 prev_*）
        if ticks_in_step >= state.snapshot().tick_ms // 16:
            prev_snap = state.snapshot()         # ✅ step 前：旧位置 A
            state = state.step()                 # snapshot 变新位置 B
            prev_body = tuple((p.x, p.y) for p in prev_snap.snake_body)
            # 修订 P2-1：吃食节拍 prev_food 传 None（食物不插值，视觉不"滑行"）
            cur_snap = state.snapshot()
            prev_food_grid = (
                (prev_snap.food.x, prev_snap.food.y)
                if prev_snap.food == cur_snap.food
                else None
            )
            ticks_in_step = 0

        snap = state.snapshot()                  # 当前帧的 B 位置
        alpha = ticks_in_step / (snap.tick_ms // 16) if snap.tick_ms > 16 else 1.0
        interp = InterpolationState(
            alpha=alpha,
            prev_snake_body=prev_body,            # A
            prev_food=prev_food_grid,             # A 或 None（吃食节拍）
        ) if alpha < 1.0 else None

        hud = HudData(score=snap.score, high_score=highscore_store.load(),
                      length=snap.length, difficulty_label=snap.difficulty.name,
                      status_label=snap.status.name)
        renderer.render(snap, hud, interp=interp)
        pygame.display.flip()
        metric = renderer.fps_metric()
        ticks_in_step += 1
        clock.tick(60)
```
