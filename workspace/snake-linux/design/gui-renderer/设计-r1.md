## 1. 数据结构

### 1.1 基础值对象（渲染侧）

| 类型 | 字段 | 说明 |
|------|------|------|
| `Color` | `r: int`、`g: int`、`b: int`（0–255） | RGB 颜色三元组；渲染侧独立于 game-core 的 Point/Direction |
| `Rect` | `x: int`、`y: int`、`w: int`、`h: int` | 屏幕像素矩形；用于 HUD 区域与绘制原语 |

> **设计原则**：renderer 不复用 game-core 的 `Point`（避免渲染层对游戏层坐标语义产生隐式耦合）；渲染侧坐标一律为像素整数，转换（grid→pixel）由 renderer 内部完成。

### 1.2 皮肤数据结构（迭代 1 仅占位 + 经典皮肤）

```python
@dataclass(frozen=True)
class Skin:
    name: str                                # "classic" / "dark" / "colorblind_friendly"（后两者迭代 3）
    background: Color                        # 背景填充
    grid_line: Color                         # 网格线（迭代 1 可选显示）
    snake_head: Color                        # 蛇头
    snake_body: Color                        # 蛇身
    food: Color                              # 食物
    food_outline: Color                      # 食物描边（辨识度增强，对齐 FR-08）
    hud_text: Color                          # HUD 文本
    hud_accent: Color                        # HUD 强调色（最高分 / 状态标签）
```

迭代 1 内置常量：

```python
DEFAULT_SKIN = Skin(
    name="classic",
    background=Color(18, 18, 24),     # 深灰蓝
    grid_line=Color(30, 30, 40),
    snake_head=Color(120, 220, 120),  # 鲜绿
    snake_body=Color(60, 180, 90),    # 稍深绿
    food=Color(230, 80, 80),          # 红
    food_outline=Color(255, 240, 220),
    hud_text=Color(230, 230, 240),
    hud_accent=Color(255, 210, 90),   # 金黄强调
)
```

### 1.3 渲染布局常量（迭代 1 固定尺寸，不做缩放）

```python
WINDOW_WIDTH = 640          # 窗口宽（像素）
WINDOW_HEIGHT = 480         # 窗口高（像素）
HUD_HEIGHT = 80             # 顶部 HUD 区域高
PLAYFIELD_X = 16            # 游戏区左上角 X 偏移（边距）
PLAYFIELD_Y = HUD_HEIGHT + 16
CELL_SIZE = 24              # 单格像素（20×15 网格 → 480×360，刚好放下）
GRID_COLS = 20              # 与 game-core 默认一致
GRID_ROWS = 15
```

不变量：迭代 1 内 `WINDOW_WIDTH = 16 + 20*24 + 16 = 512`，`WINDOW_HEIGHT = 80 + 16 + 15*24 + 16 = 472`（FO 实现时可微调 HUD/边距以容纳字号，但需在本节登记为最终常量）。

### 1.4 HUD 数据结构

HUD 内容来自 `snapshot` 字段与外部注入：

```python
@dataclass(frozen=True)
class HudData:
    score: int               # 当前局得分（来自 snapshot.score）
    high_score: int          # 历史最高分（来自 platform-storage；迭代 1 game-app 注入，渲染侧不查盘）
    length: int              # 蛇身长度（来自 snapshot.length）
    difficulty_label: str    # "EASY" / "MEDIUM" / "HARD"（来自 snapshot.difficulty.name）
    status_label: str        # "RUN" / "PAUSED" / "OVER"（来自 snapshot.status.name）
```

> **关键约束**：renderer **不直接调用** platform-storage，不感知文件路径；`high_score` 由 game-app 在主循环从 `HighScoreStore.load()` 读取后注入。renderer 是纯渲染函数，输入 = snapshot + hud_data，输出 = 屏幕像素。

### 1.5 帧率统计（性能验证）

```python
@dataclass
class FpsMetric:
    samples: Deque[float]    # 最近 N 帧渲染耗时（毫秒），容量 = 120（约 2 秒@60FPS）
    p95_frame_ms: float      # 派生属性：samples 的 P95（毫秒）
    fps: float               # 派生属性：1000 / mean(samples)
```

迭代 1 实现窗口固定（60 FPS 目标），但 `fps_metric()` 必须可读，作为 NFR-01 性能回归依据。

## 2. 数据传递方式

| 通道 | 形态 | 用途 |
|------|------|------|
| **构造注入** | `Renderer(window_size, skin=None)` | 注入初始窗口尺寸与皮肤；皮肤缺省 = DEFAULT_SKIN；**构造期不创建 pygame 屏幕**（见 §4.3 生命周期） |
| **参数传入** | `render(snapshot, hud_data) -> None` | 纯函数式绘制；输入 = snapshot + hud_data；副作用 = 写入 pygame 后台缓冲 |
| **返回值** | `fps_metric() -> FpsMetric` | 主循环读 P95 帧时间，性能验证 |
| **皮肤切换**（迭代 3 预告） | `set_skin(name: str) -> None` | 切换皮肤；**迭代 1 不暴露**，FO 在迭代 1 不写 |
| **窗口缩放**（迭代 3 预告） | `handle_resize(w: int, h: int) -> None` | 迭代 1 不暴露 |

### 2.1 输入数据流

```
game-app 主循环:
  snapshot = state.snapshot()
  hud = HudData(score=snapshot.score,
                high_score=highscore_store.load(),
                length=snapshot.length,
                difficulty_label=snapshot.difficulty.name,
                status_label=snapshot.status.name)
  renderer.render(snapshot, hud)
  pygame.display.flip()
  metric = renderer.fps_metric()
```

**renderer 不知道 game-core 的可变状态**，只读 snapshot 的不可变视图；**renderer 不访问 platform-storage**，high_score 由 app 注入。

### 2.2 异常

```python
class RenderError(RuntimeError):
    """渲染模块异常基类（pygame 初始化失败 / 颜色非法 / 字体加载失败）"""

class SkinNotFoundError(RenderError):
    """皮肤名不在注册表中（迭代 3 触发；迭代 1 仅 DEFAULT_SKIN 不会触发）"""
```

## 3. 对外接口

### 3.1 `class Renderer`

```python
class Renderer:
    def __init__(
        self,
        window_size: Tuple[int, int],       # (宽, 高) 像素
        *,
        skin: Optional[Skin] = None,        # 缺省 = DEFAULT_SKIN
        vsync: bool = True,                  # pygame.display.set_mode vsync（条件允许）
        cell_size: int = CELL_SIZE,
        grid_cols: int = GRID_COLS,
        grid_rows: int = GRID_ROWS,
    ):
        """
        - 构造期不调用 pygame.init() / pygame.display.set_mode()
          （init 拆到 __enter__ 或显式 init()，避免 import 即副作用，便于 UT）
        - 校验 window_size >= (grid_cols * cell_size + 32, grid_rows * cell_size + HUD_HEIGHT + 32)
          否则抛 RenderError（最小可玩尺寸校验，对齐 FR-09 语义，迭代 1 固定尺寸也校验以预留扩展）
        - 校验 skin 颜色 RGB 在 [0,255]
        """

    # ---- 生命周期（迭代 1 实装）----
    def init(self) -> None:
        """pygame.init() + pygame.display.set_mode(...) + pygame.font.init() + 时钟；幂等"""
    def shutdown(self) -> None:
        """pygame.display.quit() + pygame.font.quit() + pygame.quit()；幂等"""
    def __enter__(self) -> "Renderer": ...
    def __exit__(self, *exc) -> None: ...

    # ---- 绘制（迭代 1 实装）----
    def render(self, snapshot: Snapshot, hud: HudData) -> None:
        """
        一帧绘制：
        1. 用 skin.background 填充整屏
        2. 绘制网格线（可选，迭代 1 默认关闭 → 纯色背景对齐美观基线）
        3. 绘制蛇身：body[0] 用 snake_head；body[1:] 用 snake_body；相邻矩形 1 像素间隙增加辨识度
        4. 绘制食物：填充矩形 + 1 像素 outline
        5. 绘制 HUD：score / high_score / length / difficulty / status 五行
        6. 采样 fps_metric（render 开始与结束的时间差）
        """

    # ---- 帧率（迭代 1 实装）----
    def fps_metric(self) -> FpsMetric:
        """返回最近 120 帧渲染耗时的 P95 与平均 FPS"""

    # ---- 迭代 3 扩展点（迭代 1 不实装；FO 在本迭代不写这些方法，docstring 仅作接口预告）----
    # def set_skin(self, name: str) -> None: ...
    # def handle_resize(self, w: int, h: int) -> None: ...
    # def draw_animated(self, snapshot, prev_snapshot, alpha) -> None: ...  # 平滑插值
```

### 4.2 pygame 适配层（可测性关键）

**问题**：pygame 在 headless 环境（CI 容器）下 `pygame.display.set_mode()` 会失败；UT 不能依赖真实屏幕。

**方案**：在 `renderer.py` 内部所有 pygame 调用走模块顶层 import（`import pygame`），UT 通过 `monkeypatch.setattr(gui_renderer.renderer, "pygame", fake_pygame)` 注入伪 pygame：

```python
# renderer.py 顶层
import pygame
# 内部所有调用：pygame.draw.rect(surface, color, rect) / pygame.font.SysFont(...)
```

UT 用 fake_pygame 记录所有调用（draw / blit / flip），断言：
- `pygame.draw.rect` 被调用 N 次（蛇身 N 节 + 食物 1 + HUD 矩形）
- `pygame.Surface.fill` 用 background color 调用 1 次
- 字体渲染 `font.render` 被调用 5 次（HUD 5 行）

### 4.3 生命周期（init / shutdown 拆解）

```python
# game-app 调用模式
with Renderer((640, 480)) as renderer:
    while running:
        ...
        renderer.render(snapshot, hud)
        pygame.display.flip()
        metric = renderer.fps_metric()
# __exit__ → shutdown → pygame.quit()，进程可干净退出（对齐 FR-11）
```

构造期**不**调 `pygame.init()` —— 让 `Renderer(...)` 在 import 时无副作用；UT 可在 headless 环境直接 `Renderer(...)` 而不触发 SDL。

### 4.4 绘制流程（`render` 内部）

```
1. t0 = pygame.time.get_ticks()
2. screen = self._screen
3. screen.fill(self._skin.background)
4. # 可选：网格线（迭代 1 默认关闭，节省像素填充）
5. for i, cell in enumerate(snapshot.snake_body):
       px, py = grid_to_pixel(cell)
       color = self._skin.snake_head if i == 0 else self._skin.snake_body
       pygame.draw.rect(screen, color, (px, py, CELL_SIZE - 1, CELL_SIZE - 1))
6. fpx, fpy = grid_to_pixel(snapshot.food)
   pygame.draw.rect(screen, self._skin.food, (fpx, fpy, CELL_SIZE - 1, CELL_SIZE - 1))
   pygame.draw.rect(screen, self._skin.food_outline, (fpx, fpy, CELL_SIZE - 1, CELL_SIZE - 1), width=1)
7. draw_hud(screen, hud, self._skin)  # 5 行文本 + 1 行状态标签
8. t1 = pygame.time.get_ticks()
9. self._samples.append(t1 - t0)
```

### 4.5 网格→像素转换

```python
def grid_to_pixel(self, cell: Point) -> Tuple[int, int]:
    return (PLAYFIELD_X + cell.x * CELL_SIZE, PLAYFIELD_Y + cell.y * CELL_SIZE)
```

> **game-core 的 Point 复用决策**：renderer 在 `render(snapshot, ...)` 入参处**直接读** `snapshot.snake_body`（tuple of Point from game-core），但**不显式 import game_core.types.Point**（避免循环依赖风险）；`grid_to_pixel` 接受 `Tuple[int, int]`（即 `(x, y)`），调用方 `renderer._grid_to_pixel((cell.x, cell.y))` 显式拆包。
>
> 理由：renderer 对 game-core 的依赖仅"读 snapshot 字段"，字段类型在 Snapshot 的契约里已声明（`Tuple[Point, ...]`）；renderer 只需要坐标整数，不需要 Point 类本身。

### 4.6 HUD 绘制

```
顶部 HUD 区（HUD_HEIGHT = 80 像素）：
  ┌─────────────────────────────────────────────┐
  │  Score:  42   High:  128    Length:  15    │   ← 第 1 行（主信息）
  │  Difficulty: MEDIUM     Status: RUN         │   ← 第 2 行（状态）
  └─────────────────────────────────────────────┘
```

- 字体：`pygame.font.SysFont("Arial", 22)`（回退 `pygame.font.Font(None, 22)` 即 SDL 默认字体）
- 行高：28 像素；首行 y = 12，第二行 y = 44
- 颜色：`hud_text`（主色）/ `hud_accent`（强调，用于 High Score / Status）
- `Status: OVER` 时状态文字用 `hud_accent` 高亮（金黄色，对齐美观基线）

### 4.7 帧率采样

- 容量 120 samples（约 2 秒 @ 60FPS）
- 每次 `render` 末尾采样耗时（ms）
- `fps_metric()` 返回：
  - `p95_frame_ms` = `statistics.quantiles(samples, n=20)[-1]`（95% 分位）
  - `fps` = `1000 / mean(samples)`
- samples < 20 时 P95 返回 `mean`（避免 quantiles 抛错）；这是**降级而非异常**

## 5. DFx / 可测试性 / 鲁棒性 / 韧性

### 5.1 可测试性（Testability）

| 设计 | 收益 |
|------|------|
| 构造期不调 `pygame.init()` | UT 在 headless 直接 `Renderer(...)` 不触发 SDL |

| `render` 输入 = 不可变 snapshot + HudData | UT 用 dataclass fixture 构造，无需 mock game-core |

| `DEFAULT_SKIN` 模块级常量 | UT 断言"经典皮肤含 green-head"等契约 |
| 颜色 RGB 范围校验在 Renderer.__init__ | UT 用 `assertRaises(RenderError)` 覆盖非法色 |

| 失败场景 | 处理 | 异常 |
|----------|------|------|
| pygame 初始化失败（无图形环境） | init() 抛出 RenderError | 是（让 game-app 走 NFR-03 友好提示） |
| 字体加载失败 | 回退 `pygame.font.Font(None, size)` 即 SDL 默认字体 | 否（降级而非异常） |
| 窗口尺寸过小 | __init__ 校验最小可玩尺寸 → RenderError | 是 |
| 颜色 RGB 越界 | __init__ 校验 → RenderError | 是 |
| render 时 snapshot 为 None | 立即抛 RenderError（断言） | 是 |
| fps 样本数 < 20 | P95 降级为 mean | 否 |
| 蛇身坐标越界网格 | grid_to_pixel 仍返回像素值（可能落在窗口外） | 否（接受，由 game-core INV-3 保证不越界） |

### 5.6 韧性（Resilience）

- 渲染失败**不破坏**游戏逻辑：renderer 抛 RenderError 时 game-app 捕获并友好提示（NFR-03）；game-core 状态不变。
- pygame.quit() 在 `__exit__` 幂等调用——重复 shutdown 不报错（FR-11 退出 1 秒内无残留进程）。

### 5.7 安全 / 隐私（NFR-06 同步收紧）

- 模块不 import `socket` / `urllib` / `http` / `requests`（FO 实现时 grep 校验）
- 不向文件 / 网络写任何数据（renderer 是只读 snapshot + 写像素）

## 8. 与 game-app 的对接契约（接口示意）

虽然 game-app 不在本模块设计范围，但 renderer 必须按下列契约接收数据：

```python
# game-app 主循环（伪代码，FO 在 game-app 设计里会有更详细版本）
from game_core import GameState, Snapshot
from platform_storage import HighScoreStore
from gui_renderer import Renderer, HudData

highscore_store = HighScoreStore()  # 迭代 2 接入；迭代 1 game-app 可传 0
with Renderer((640, 480)) as renderer:
    state = GameState(20, 15, Difficulty.MEDIUM)
    clock = pygame.time.Clock()
    running = True
    while running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT: running = False
            # WASD / 方向键 / P / ESC 由 game-app 处理 → state.set_direction / state.step / state.toggle_pause
            ...
        # 每帧：core.step 推进（按 snapshot.tick_ms 控速）+ 渲染
        state = state.step()
        hud = HudData(
            score=state.snapshot().score,
            high_score=highscore_store.load(),
            length=state.snapshot().length,
            difficulty_label=state.snapshot().difficulty.name,
            status_label=state.snapshot().status.name,
        )
        renderer.render(state.snapshot(), hud)
        pygame.display.flip()
        clock.tick(60)
```

## 9. 附录：迭代 3 增量接口预告（FO 不实现，仅留扩展点）

| 接口 | 签名 | 用途 |
|------|------|------|
| `set_skin` | `(name: str) -> None` | 切皮肤；从 `_skin_registry` 字典查；不在 → SkinNotFoundError；调用后立即生效（下一帧 render 用新皮肤） |
