## 1. 数据结构

### 1.1 界面状态枚举（app 层级，独立于 core 的 GameStatus）

| 类型 | 字段 | 说明 |
|------|------|------|
| `AppScreen`（Enum） | `MENU` / `PLAYING` / `GAME_OVER` | app 顶层界面状态机；迭代 1 仅 3 态；PAUSED 枚举**不**在迭代 1 出现（迭代 2 加） |
| `InputAction`（Enum） | `QUIT` / `START` / `MOVE_UP` / `MOVE_DOWN` / `MOVE_LEFT` / `MOVE_RIGHT` / `TOGGLE_PAUSE` / `RESTART` / `SELECT_EASY` / `SELECT_MEDIUM` / `SELECT_HARD` | 输入归一化结果，pygame 事件 → InputAction 映射（见 §4.3） |

### 1.2 难度选择状态（菜单内子状态，R2-7：单一模型）

| 类型 | 字段 | 说明 |
|------|------|------|
| `_selected_difficulty: Difficulty` | class 内部 state | 菜单态当前选中难度（默认 `Difficulty.MEDIUM`）；1/2/3 键直接改写，按 START/Enter 启动新 `GameState` |
| ~~`MenuCursor`（Enum）~~ | 已删除（R2-7，r1 中为死代码 / 与 1/2/3 单键选择混用） |

### 1.3 运行期状态（app 内部 mutable state，不暴露给 core）

| 字段 | 类型 | 说明 |
|------|------|------|
| `screen: AppScreen` | 当前界面 | 初始 `MENU` |
| `difficulty: Difficulty` | 当前局难度 | 初始 `MEDIUM`；选定后固化到 `GameState`，**游戏中不可改**（对齐 FR-05） |
| `game_state: Optional[GameState]` | 玩法状态 | 仅在 `PLAYING` / `GAME_OVER` 态非 None；`MENU` 态 = None（r1 设计如此但 _render 会崩；R2-5 见 §4.6 重写为菜单自绘规避） |
| `renderer: Renderer` | 渲染器 | 构造时 `Renderer((640, 480), skin=DEFAULT_SKIN)`，主循环启动时 `renderer.init()` 一次（R2-2） |
| `clock: pygame.time.Clock` | 帧率控制 | `clock.tick_busy_loop(fps_cap)` |
| `high_score: int` | 最高分占位 | 迭代 1 写死 0；迭代 2 替换为 `HighScoreStore(...).load()` |
| `_tick_accumulator_ms: int` | 内部节拍累计 | 累加 frame 间隔，达到 `tick_ms` 时调 `game_state.step()` 一次；防止 pygame 时钟抖动 |
| `_pause_hint_shown: bool` | P 键占位标志 | 渲染 HUD 时在右侧加"按 P = 暂停（迭代 2 启用）"小字（R2-11） |
| `event_queue: List[pygame.event.Event]` | UT 注入 | 默认 = `pygame.event.get()`；conftest 可替成假队列 |
| `_menu_font: pygame.font.Font` | 菜单自绘字体 | MENU/GAME_OVER 自绘用；构造期 `pygame.font.SysFont(name, size)` |
| `_hud_font: pygame.font.Font` | 内部预留 | 实际 HUD 文字由 renderer 内部字体绘制；保留以便未来扩展 |

### 1.4 不变量清单（FO 实现必须保证，UT 也要覆盖）

| ID | 不变量 |
|----|--------|
| INV-1 | `screen == PLAYING` 时 `game_state.status == GameStatus.RUN` |
| INV-2 | `screen == GAME_OVER` 时 `game_state.status == GameStatus.OVER` |
| INV-3 | 难度 `Difficulty` 选定后写入 `game_state.difficulty`，运行中**无接口**可改（game-core **无 set_difficulty 方法**；难度固化于 GameState 字段，game-core 纯函数语义保证，R2-17） |

## 2. 数据传递方式

### 2.1 模块边界与数据流

```
                 ┌──────────────────────────────┐
   键盘事件 ───▶ │  InputMap: pygame.event →    │ ──▶ InputAction (Enum)
                 │       InputAction             │
                 └──────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────┐
   │  主循环 (run())                                               │
   │   1. clock.tick(fps_cap) → dt_ms                             │
   │   2. drain_events() → InputAction 流                        │
   │   3. if QUIT in actions: break                               │
   │   4. for a in actions: dispatch(screen, a)                   │
   │   5. if screen==PLAYING: tick(dt_ms) → step 节拍            │
   │         if status==OVER → screen=GAME_OVER                   │
   │   6. render():                                                │
   │        MENU        → app._draw_menu()       （pygame 自绘） │
   │        PLAYING     → renderer.render(snap, hud)             │
   │        GAME_OVER   → app._draw_game_over()  （pygame 自绘） │
   │   7. pygame.display.flip()                                    │
   └─────────────────────────────────────────────────────────────┘
                            │
                ┌───────────┼───────────┐
                ▼           ▼           ▼
            game-core   gui-renderer  (platform-storage 迭代 2 接入)
```

> **R2-5 关键变化**：MENU / GAME_OVER 态由 app **自绘**（直接 `pygame.font / pygame.draw`），**完全不调** `renderer.render`；renderer.render 仅在 PLAYING 态调用，且传入 `snapshot.snake_body` 非空的快照。

### 2.2 模块间参数

| 方向 | 路径 | 类型 |
|------|------|------|
| app → core | `_new_game(difficulty) -> GameState` | `GameState(width=20, height=15, difficulty=..., rng=Random())` （**关键字参数**，R2-4） |
| app → core | `game_state.set_direction(direction)` | `Direction` |
| app → core | `game_state.step()` | 无参 → `GameState`（新对象，纯函数语义） |
| app → core | `game_state.snapshot()` | 无参 → `Snapshot`（值对象，含 tick_ms / score / length / status / difficulty） |
| app → renderer | `Renderer((640, 480), skin=DEFAULT_SKIN)` | 构造 |
| app → renderer | `renderer.init()` / `shutdown()` / `with` 上下文 | 生命周期；**必须 init 才能 render**（R2-2） |
| app → renderer | `renderer.render(snapshot, hud: HudData)` | PLAYING 态每帧；snapshot + HudData 5 字段 dataclass（R2-1/R2-3） |
| core → app | `InvalidStateError` | OVER / PAUSED 调 set_direction/step/toggle_pause 时抛；app **捕获并** 转为状态切换（INV-1/2 保护下迭代 1 应不可达） |
| 迭代 2 接入 | core `set_score_callback(cb)` | 注册得分事件回调（替代 r1 中误引的 `on_score`，R2-15） |

### 2.3 存储 / 共享状态

- **进程内单例**：app 状态全部活在 `App` 类实例字段，**无全局变量**（除 pygame 自身的 `pygame.init()` 副作用）。
- **进程间无共享**：无 IPC、无 socket、无文件锁。
- **磁盘写入**：迭代 1 写 0 字节；迭代 2 通过 `platform_storage.get_user_data_dir()` + `HighScoreStore` 落 `highscore.json`。

### 3.4 `App` 主类（R2-1/2/3/4/5 关键修订）

```python
class App:
    """snake-gui 顶层装配；PyInstaller 入口。"""

    def __init__(self, config: AppConfig = AppConfig()) -> None:
        """初始化 renderer/clock；初始 screen=MENU, difficulty=MEDIUM, game_state=None；
        renderer 在 run() 内调 init()（不在构造期，以满足"无副作用 import 原则"）。"""

    def run(self) -> int:
        """主循环。返回进程退出码（0 正常 / 1 异常 / 2 图形环境不可用）。"""

    # --- 内部接口（UT 注入 / 桩替） ---

    def _drain_events(self) -> List[InputAction]: ...
        """本帧所有 pygame 事件归一化；QUIT 优先 break。"""

    def _dispatch(self, action: InputAction) -> None:
        """按当前 screen 分发：MENU 改 difficulty / START 开局；PLAYING 推方向 / 暂停占位；GAME_OVER 重开 / 退出。"""

    def _new_game(self, difficulty: Difficulty) -> None:
        """game_state = GameState(width=20, height=15, difficulty=difficulty, rng=random.Random())；
        screen=PLAYING。（**全关键字**，R2-4）"""

    def _tick(self, dt_ms: int) -> None:
        """PLAYING 态推进节拍；累计到 tick_ms 时 step()；OVER 自动转 GAME_OVER。"""

    def _render(self) -> None:
        """按 screen 分发：
           MENU        → _draw_menu()
           PLAYING     → _build_hud() + renderer.render(snap, hud) + pygame.display.flip()
           GAME_OVER   → _draw_game_over()
        """

    def _build_hud(self) -> HudData:
        """构造 HudData dataclass（5 字段：score/high_score/length/difficulty_label/status_label）。
        HUD 文字由 renderer 内部字体绘制，本方法仅组装数据。"""

    def _draw_menu(self) -> None:
        """MENU 态自绘（pygame.font + pygame.draw）：
           - 标题 'Snake GUI v2.0.0'（大字、居中）
           - 副标 '按 1=简单 / 2=普通 / 3=困难 选难度'
           - '按 Enter / 任意键 开始'
           - 当前选中难度高亮框
           - 'Q 退出'
        """

    def _draw_game_over(self) -> None:
        """GAME_OVER 态自绘：'Game Over' 标题 + 最终得分 + 'R 重开  Q 退出'。"""

    def _quit(self) -> None:
        """QUIT 通道的主循环退出点（R2-8）：只设置 self._running = False，主循环检测后 break + finally 关闭。
        （不再用 _quit_requested 标志位）"""
```

### 4.2 主循环骨架（R2-8 单一 QUIT 通道）

```python
def run(self) -> int:
    try:
        self._init_pygame()        # 构造 renderer + renderer.init()；失败抛 GraphicsUnavailableError
    except GraphicsUnavailableError as e:
        print(f"[错误] 无法初始化图形界面: {e}\n请确认系统有可用的图形环境。", file=sys.stderr)
        return 2

    try:
        while self._running:                                 # R2-8：单一 _running 标志
            dt_ms = self.clock.tick_busy_loop(self.config.fps_cap)
            actions = self._drain_events()
            if InputAction.QUIT in actions:                  # R2-8：外层唯一 break 通道
                break
            for a in actions:
                self._dispatch(a)
            if self.screen == AppScreen.PLAYING:
                self._tick(dt_ms)
            self._render()                                   # 屏幕态分发（R2-5）
        return 0
    except AppError as e:
        print(f"[错误] {e}", file=sys.stderr)
        return 1
    finally:
        try:
            self._renderer.shutdown()                       # INV-5：幂等，重复调安全
        except Exception:
            pass  # shutdown 兜底，不让异常覆盖 return 码
```

### 4.3 输入映射（_map_event，R2-9 任意键 START）

```python
# input.py
import pygame

_DIFFICULTY_KEYS = {
    pygame.K_1: InputAction.SELECT_EASY,
    pygame.K_2: InputAction.SELECT_MEDIUM,
    pygame.K_3: InputAction.SELECT_HARD,
}

_DIRECTION_KEYS = {
    pygame.K_w: InputAction.MOVE_UP, pygame.K_UP: InputAction.MOVE_UP,
    pygame.K_s: InputAction.MOVE_DOWN, pygame.K_DOWN: InputAction.MOVE_DOWN,
    pygame.K_a: InputAction.MOVE_LEFT, pygame.K_LEFT: InputAction.MOVE_LEFT,
    pygame.K_d: InputAction.MOVE_RIGHT, pygame.K_RIGHT: InputAction.MOVE_RIGHT,
}

def _map_event(event: pygame.event.Event) -> Optional[InputAction]:
    if event.type == pygame.QUIT:
        return InputAction.QUIT
    if event.type != pygame.KEYDOWN:
        return None
    k = event.key
    if k in (pygame.K_q, pygame.K_ESCAPE):
        return InputAction.QUIT  # 全局退出
    if k == pygame.K_p:
        return InputAction.TOGGLE_PAUSE
    if k == pygame.K_r:
        return InputAction.RESTART
    if k in _DIFFICULTY_KEYS:
        return _DIFFICULTY_KEYS[k]
    if k in _DIRECTION_KEYS:
        return _DIRECTION_KEYS[k]
    # R2-9：MENU 态未映射的 KEYDOWN 视为 START（满足 FR-11 "按任意键开始"）
    # PLAYING/GAME_OVER 态未映射 KEYDOWN → None（不归一为 START）
    # 实现：_map_event 不感知 screen；调用方（MENU dispatch）把 None 视为 START
    # —— 见 _dispatch_menu 的 "if action is None: self._new_game(self._difficulty)"
    return None
```

> 注：R2-9 的"任意键开始"语义通过 `_dispatch_menu` 显式处理：MENU 态下若当前 action 既非 `SELECT_*` 也非 `QUIT`，视为 START。其他态不处理 None。`_map_event` 保持纯净。

```python
# app.py
def _dispatch(self, action: InputAction) -> None:
    if self.screen == AppScreen.MENU:
        self._dispatch_menu(action)
    elif self.screen == AppScreen.PLAYING:
        self._dispatch_playing(action)
    elif self.screen == AppScreen.GAME_OVER:
        self._dispatch_over(action)

def _dispatch_menu(self, action: InputAction) -> None:
    if action == InputAction.SELECT_EASY:
        self._difficulty = Difficulty.EASY
    elif action == InputAction.SELECT_MEDIUM:
        self._difficulty = Difficulty.MEDIUM
    elif action == InputAction.SELECT_HARD:
        self._difficulty = Difficulty.HARD
    elif action == InputAction.START:
        self._new_game(self._difficulty)
    elif action == InputAction.QUIT:
        self._running = False  # R2-8：单一通道，删 _quit_requested
    elif action is None:
        # R2-9：MENU 态未映射的 KEYDOWN（DrainEvents 保留原始 event 并识屏态兜底）
        # 由 _drain_events 已在 MENU 态把 None 替换为 START；这里不再处理 None
        pass

def _dispatch_playing(self, action: InputAction) -> None:
    if action == InputAction.MOVE_UP:
        self.game_state = self.game_state.set_direction(Direction.UP)
    elif action == InputAction.MOVE_DOWN:
        self.game_state = self.game_state.set_direction(Direction.DOWN)
    elif action == InputAction.MOVE_LEFT:
        self.game_state = self.game_state.set_direction(Direction.LEFT)
    elif action == InputAction.MOVE_RIGHT:
        self.game_state = self.game_state.set_direction(Direction.RIGHT)
    elif action == InputAction.TOGGLE_PAUSE:
        # 迭代 1 占位：仅置 _pause_hint_shown=True（HUD 显示"按 P = 暂停（迭代 2）"）
        # **迭代 1 不调 game_state.toggle_pause()**（核心函数 P 占位）
        self._pause_hint_shown = True

def _dispatch_over(self, action: InputAction) -> None:
    if action == InputAction.RESTART:
        self._new_game(self._difficulty)
    elif action == InputAction.QUIT:
        self._running = False
```

> R2-7 修订：`MenuCursor` 死代码已删除（R1 时存在但从未被引用），`_dispatch_menu` 入口仅由 SELECT_EASY/MEDIUM/HARD 改 `_difficulty`。

### 4.5 节拍推进（_tick）

```python
def _tick(self, dt_ms: int) -> None:
    """PLAYING 态累加节拍；当 >= tick_ms 时 step 一次；OVER 自动转 GAME_OVER。"""
    assert self.screen == AppScreen.PLAYING
    assert self.game_state is not None
    self._tick_accumulator_ms += dt_ms
    tick_ms = self.game_state.snapshot().tick_ms
    while self._tick_accumulator_ms >= tick_ms:
        self._tick_accumulator_ms -= tick_ms
        self.game_state = self.game_state.step()
        if self.game_state.status == GameStatus.OVER:
            self.screen = AppScreen.GAME_OVER
            self._pause_hint_shown = False
            break
```

### 4.7 初始化（R2-1 / R2-2 窗口职责统一 + R2-5 渲染分发）

```python
def _init_pygame(self) -> None:
    """构造 renderer + 调 init()；窗口职责唯一交给 renderer（R2-2）。
    失败时 pygame.error → GraphicsUnavailableError，exit code 2。"""
    try:
        # R2-1：window_size 二元组 + skin=DEFAULT_SKIN；不再用字符串 "classic"
        # R2-10：window_size 与 AppConfig.window_w/h 一致
        self._renderer = Renderer(
            (self.config.window_w, self.config.window_h),  # (640, 480)
            skin=DEFAULT_SKIN,
        )
        self._renderer.init()                              # R2-2：必须在 render 前调
        # R2-2：删除 app 自身的 display.set_mode 调用（由 renderer.init 内 set_mode 独占）
    except (RenderError, pygame.error) as e:
        raise GraphicsUnavailableError(str(e)) from e

    # 自绘菜单 / 结束画面所需字体（R2-5）
    try:
        self._menu_title_font = pygame.font.SysFont("Arial", 48, bold=True)
        self._menu_body_font = pygame.font.SysFont("Arial", 22)
    except Exception:
        self._menu_title_font = pygame.font.Font(None, 48)  # SDL 默认字体兜底
        self._menu_body_font = pygame.font.Font(None, 22)

    self.clock = pygame.time.Clock()
```

### 4.8 渲染分发（R2-5 按 screen 分发）

```python
def _render(self) -> None:
    """按 screen 分发：MENU/游戏结束自绘；PLAYING 走 renderer。
    pygame.display.flip() 在所有路径末尾统一调。"""
    if self.screen == AppScreen.MENU:
        self._draw_menu()                                 # R2-5：app 自绘
    elif self.screen == AppScreen.PLAYING:
        # R2-5：renderer.render 只在 PLAYING 调，game_state 非 None
        snap = self.game_state.snapshot()
        hud = self._build_hud()
        self._renderer.render(snap, hud)
    elif self.screen == AppScreen.GAME_OVER:
        self._draw_game_over()                            # R2-5：app 自绘（用 self.game_state.snapshot().score）
    pygame.display.flip()
```

### 4.10 实现注意点

1. **无全局变量**：app 状态全部在 `App` 实例字段，UT 可通过构造多个 `App` 实例隔离测试。
2. **pygame 副作用隔离**：`pygame.init()` / `pygame.quit()` 调用次数在 UT 中通过 fake pygame 模块统计（详见 §6.2）。
3. **不直接读 game_state 内部字段**：所有访问走 `snapshot()`；修改走 `set_direction` / `step`（返回新对象）。
4. **不直接调 renderer 私有方法**：仅 `Renderer((W,H), skin=DEFAULT_SKIN)` 构造 + `init/shutdown` + `render(snap, hud)` + 读 `skin` property。
5. **不引入 `time.sleep`**：所有延迟靠 `clock.tick_busy_loop(fps_cap)` + `_tick_accumulator_ms`。
6. **不 import platform_storage**：迭代 1 不调 `get_user_data_dir()` / `HighScoreStore`（对齐迭代边界）。
7. **不写任何文件**：迭代 1 进程不创建任何磁盘文件（无 log、无 config、无存档）。
8. **退出码约定**：0 正常 / 1 app 异常 / 2 图形环境不可用（NFR-03 最小集）。
9. **HUD `status_label` 必填**（R2-3）：renderer 第 2 行 `Status: ...` 必读，缺则 AttributeError；`_STATUS_LABEL[snap.status]` 在三种状态均有值。
10. **renderer.skin 只读**（R2-2）：迭代 1 仅 `DEFAULT_SKIN`，**不调** `set_skin`（gui-renderer iter-1 无此方法，迭代 3 接入）。

- **`_drain_events` 注入事件流**（R2-16）：`conftest.py` 提供 `event_queue: List[pygame.event.Event]` fixture，`App.__init__` 通过 monkeypatch 替换 `pygame.event.get` 为 `lambda: event_queue.pop(0) or []`，让端到端 UT 用例 28 可注入多事件序列。
- **InputAction 归一化层独立**：`test_input_map.py` 单独测事件 → Action 映射。
- **`_tick` 纯函数**：调 `_tick(160)` 不依赖 `clock`，UT 可传任意 dt_ms。
- **`_dispatch_*` 状态机可枚举**：每态 × 每 action 用 `pytest.mark.parametrize`。
- **`_build_hud` 返 dataclass**：`_build_hud()` 返 `HudData`，UT 直接断言字段值（int / str）。
- **`_render` 分发可测**：`test_app_render_dispatch.py` 用 fake_pygame 验证三态分别走 `_draw_menu` / `renderer.render` / `_draw_game_over`。
- **错误路径可触发**：`_init_pygame` 通过 fake pygame `set_mode` 抛 `pygame.error` → 测 `GraphicsUnavailableError` 传播。

### 5.5 鲁棒性 / 韧性

| 场景 | 处理 |
|------|------|
| 图形环境缺失 | `Renderer.init()` 抛 `RenderError` → `GraphicsUnavailableError` → 退出码 2 + 人类可读 stderr |
| 同一帧多事件 | `_drain_events` 返 list；主循环按序处理；QUIT 优先 break |
| 反向输入 | 透传到 `core.set_direction`；core 内静默忽略（长度 ≥2）/ 放行（长度 1）（对齐 FR-02） |
| 撞墙/撞身 | `core.step` 返回 `status=OVER`；`_tick` 检测后自动转 `GAME_OVER`（INV-2） |
| 关窗 | `pygame.QUIT` 事件 → `QUIT` action → 主循环 break → `renderer.shutdown()` |
| OVER 态继续按方向键 | `_dispatch_playing` 在 OVER 屏不会被调用（已转 GAME_OVER），无副作用 |
| Q/ESC 任意态 | `_map_event` 统一映射 `QUIT` action；主循环检测后 `_running=False` → break（R2-8） |
| 节拍漂移 | `_tick_accumulator_ms` 用累加 + while 循环，**不丢节拍**（慢帧会追跑多次 step） |
| 配置非法（fps_cap ≤ 0） | `AppConfig.__post_init__` 抛 `ConfigError`；`main()` 捕获后 stderr + 退出码 1 |
| MENU 态访问 game_state | INV-7：`_render` 在 MENU / GAME_OVER 态不调 `renderer.render`，避免 `None.snapshot()` 崩（R2-5） |

### 5.6 错误处理矩阵

| 错误情形 | 行为 |
|----------|------|
| `Renderer.init()`（内部 `pygame.init()`）失败 | `RenderError`（runtime error） → 包装为 `GraphicsUnavailableError` → 退出码 2 |
| `Renderer.__init__` 校验失败（window_size 不合规） | 同上 |
| 构造 `App(fps_cap=0)` | `ConfigError`（`__post_init__` 校验） |
| 构造 `App(window_w < min_window_w)` | `ConfigError`（迭代 1 默认值已合规，仅防 FO 误传） |
| `App.run()` 中 `core` 抛 `InvalidStateError` | 理论上迭代 1 不可达（INV-1/2 保护）；UT 覆盖；若真发生 → `AppError` 子类包装 → 退出码 1 |
| `App.run()` 中未捕获异常 | 兜底 `except Exception` → stderr traceback + 退出码 1（迭代 4 收敛为更友好提示） |
