## 2. 数据传递方式

### 2.1 模块边界与数据流

```
                 ┌──────────────────────────────┐
   键盘事件 ───▶ │  InputMap: pygame.event →    │ ──▶ InputAction (Enum)
                 │       _map_event (单键)       │       (含 None: 未映射)
                 └──────────────────────────────┘
                            │
                            ▼
                 ┌──────────────────────────────┐
                 │ _drain_events (R3-1 屏态兜底) │
                 │   MENU 屏态:                  │
                 │     None/方向键/WASD/字母/数字 │
                 │     ──→ InputAction.START    │
                 │   其他屏态: 不变              │
                 └──────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────┐
   │  主循环 (run())                                               │
   │   1. clock.tick(fps_cap) → dt_ms                             │
   │   2. _drain_events() → InputAction 流                       │
   │   3. if QUIT in actions: break  (R2-8 单一通道)              │
   │   4. for a in actions: _dispatch(screen, a)                  │
   │   5. if screen==PLAYING: _tick(dt_ms) → step 节拍            │
   │         if status==OVER → screen=GAME_OVER                   │
   │   6. _render():                                              │
   │        MENU        → menu.draw_menu(...)     (pygame 自绘)  │
   │        PLAYING     → renderer.render(snap, hud)              │
   │        GAME_OVER   → menu.draw_game_over(...) (pygame 自绘)  │
   │   7. pygame.display.flip()                                    │
   └─────────────────────────────────────────────────────────────┘
                            │
                ┌───────────┼───────────┐
                ▼           ▼           ▼
            game-core   gui-renderer  (platform-storage 迭代 2 接入)
```

> **R3-1 关键变化**：`None → START` 转换点**唯一**在 `_drain_events`（屏态兜底）；`_map_event` 仅做单键归一化（不感知屏态，返 None 表示"未映射"）；`_dispatch_menu` 收到 None 已不可能（drain 处兜底完成）。
>
> **R2-5 关键变化**：MENU / GAME_OVER 态由 app **自绘**（直接 `pygame.font / pygame.draw`），**完全不调** `renderer.render`；renderer.render 仅在 PLAYING 态调用。

### 2.2 模块间参数

| 方向 | 路径 | 类型 |
|------|------|------|
| app → core | `_new_game(difficulty) -> None` | `GameState(width=20, height=15, difficulty=..., rng=Random())` （**全关键字**，R2-4） |
| app → core | `game_state.set_direction(direction)` | `Direction` |
| app → core | `game_state.step()` | 无参 → `GameState`（新对象，纯函数语义） |
| app → core | `game_state.snapshot()` | 无参 → `Snapshot`（值对象，含 tick_ms / score / length / status / difficulty） |
| app → renderer | `Renderer((640, 480), skin=DEFAULT_SKIN)` | 构造 |
| app → renderer | `renderer.init()` / `shutdown()` / `with` 上下文 | 生命周期；**必须 init 才能 render** |
| app → renderer | `renderer.render(snapshot, hud: HudData)` | PLAYING 态每帧；snapshot + HudData 5 字段 dataclass |
| core → app | `InvalidStateError` | OVER / PAUSED 调 set_direction/step/toggle_pause 时抛；迭代 1 **理论不可达**（INV-1/2 保护，R3-9 不包装） |
| 迭代 2 接入 | core `set_score_callback(cb)` | 注册得分事件回调 |

### 2.3 存储 / 共享状态

- **进程内单例**：app 状态全部活在 `App` 类实例字段，**无全局变量**（除 pygame 自身的 `pygame.init()` 副作用）。
- **进程间无共享**：无 IPC、无 socket、无文件锁。
- **磁盘写入**：迭代 1 写 0 字节；迭代 2 通过 `platform_storage.get_user_data_dir()` + `HighScoreStore` 落 `highscore.json`。

### 4.2 主循环骨架（R2-8 单一 QUIT 通道 + R3-15 退出码 2 shutdown 兜底）

```python
def run(self) -> int:
    self._renderer = None
    try:
        self._init_pygame()        # 构造 renderer + renderer.init()；失败抛 GraphicsUnavailableError
    except GraphicsUnavailableError as e:
        print(f"[错误] 无法初始化图形界面: {e}\n请确认系统有可用的图形环境。", file=sys.stderr)
        return 2

    try:
        while self._running:                                 # R2-8：单一 _running 标志
            dt_ms = self.clock.tick_busy_loop(self.config.fps_cap)
            actions = self._drain_events()
            if InputAction.QUIT in actions:                  # R2-8：外层唯一 break 通道
                break
            for a in actions:
                self._dispatch(a)
            if self.screen == AppScreen.PLAYING:
                self._tick(dt_ms)
            self._render()
        return 0
    except AppError as e:
        print(f"[错误] {e}", file=sys.stderr)
        return 1
    finally:
        try:
            # INV-5：render 成功的退出路径 shutdown 一次
            # 退出码 2 路径在更外层 try/finally 也兜底（见下方 try-2）
            if self._renderer is not None:
                self._renderer.shutdown()
        except Exception:
            pass  # shutdown 兜底，不让异常覆盖 return 码
```

### 4.3 输入映射（_map_event，**R3-1 重要：仅做单键归一，不感知屏态**）

```python
# input.py
import pygame

_DIFFICULTY_KEYS = {
    pygame.K_1: InputAction.SELECT_EASY,
    pygame.K_2: InputAction.SELECT_MEDIUM,
    pygame.K_3: InputAction.SELECT_HARD,
}

_DIRECTION_KEYS = {
    pygame.K_w: InputAction.MOVE_UP, pygame.K_UP: InputAction.MOVE_UP,
    pygame.K_s: InputAction.MOVE_DOWN, pygame.K_DOWN: InputAction.MOVE_DOWN,
    pygame.K_a: InputAction.MOVE_LEFT, pygame.K_LEFT: InputAction.MOVE_LEFT,
    pygame.K_d: InputAction.MOVE_RIGHT, pygame.K_RIGHT: InputAction.MOVE_RIGHT,
}

# R3-1：MENU 态保留键（这些键不被转换为 START，仍走原 action）
# 用于 _drain_events 的屏态兜底
_MENU_RESERVED_ACTIONS = frozenset({
    InputAction.QUIT,
    InputAction.SELECT_EASY, InputAction.SELECT_MEDIUM, InputAction.SELECT_HARD,
    InputAction.TOGGLE_PAUSE, InputAction.RESTART,
})


def _map_event(event: pygame.event.Event) -> Optional[InputAction]:
    """单键归一化；不感知屏态；返回 None 表示未映射（由 _drain_events 屏态兜底处理）。"""
    if event.type == pygame.QUIT:
        return InputAction.QUIT
    if event.type != pygame.KEYDOWN:
        return None
    k = event.key
    if k in (pygame.K_q, pygame.K_ESCAPE):
        return InputAction.QUIT  # 全局退出
    if k == pygame.K_p:
        return InputAction.TOGGLE_PAUSE
    if k == pygame.K_r:
        return InputAction.RESTART
    if k in _DIFFICULTY_KEYS:
        return _DIFFICULTY_KEYS[k]
    if k in _DIRECTION_KEYS:
        return _DIRECTION_KEYS[k]
    # 其他 KEYDOWN（含字母数字、鼠标等）→ None
    return None
```

### 4.4 状态机 dispatch 表 + **R3-1 `_drain_events` 屏态兜底**（全文唯一转换点）

```python
# app.py
def _drain_events(self) -> List[InputAction]:
    """本帧所有 pygame 事件归一化；QUIT 优先 break。
    **R3-1 唯一屏态兜底点**：MENU 屏态下所有 action（除保留键外）→ START。
    其他屏态（PLAYING / GAME_OVER）原样透传。"""
    raw = pygame.event.get()
    actions: List[InputAction] = []
    for ev in raw:
        action = _map_event(ev)
        if action is None and self.screen == AppScreen.MENU:
            # R3-1：MENU 态未映射 KEYDOWN → START（满足 FR-11 "按任意键开始"）
            action = InputAction.START
        elif action is not None and self.screen == AppScreen.MENU \
             and action not in _MENU_RESERVED_ACTIONS:
            # R3-1：MENU 态方向键等也归一为 START（满足"按 W/A/S/D/方向键 也能开始"）
            action = InputAction.START
        if action is not None:
            actions.append(action)
    return actions


def _dispatch(self, action: InputAction) -> None:
    if self.screen == AppScreen.MENU:
        self._dispatch_menu(action)
    elif self.screen == AppScreen.PLAYING:
        self._dispatch_playing(action)
    elif self.screen == AppScreen.GAME_OVER:
        self._dispatch_over(action)


def _dispatch_menu(self, action: InputAction) -> None:
    """MENU 态分发。R3-1 修订：None 在 _drain_events 已转为 START；不需要此处 None 分支。
    R3-7 修订：删除 QUIT 分支（主循环外层 'if QUIT in actions: break' 永远先 exit）。"""
    if action == InputAction.SELECT_EASY:
        self._difficulty = Difficulty.EASY
    elif action == InputAction.SELECT_MEDIUM:
        self._difficulty = Difficulty.MEDIUM
    elif action == InputAction.SELECT_HARD:
        self._difficulty = Difficulty.HARD
    elif action == InputAction.START:
        self._new_game(self._difficulty)
    # 其他 action（MOVE_*/TOGGLE_PAUSE/RESTART 理论上进不来，因为
    # _drain_events 在 MENU 态已把它们转 START；显式忽略以保持防御性）


def _dispatch_playing(self, action: InputAction) -> None:
    """PLAYING 态分发。R3-9：InvalidStateError 理论不可达，不包装。"""
    if action == InputAction.MOVE_UP:
        self.game_state = self.game_state.set_direction(Direction.UP)
    elif action == InputAction.MOVE_DOWN:
        self.game_state = self.game_state.set_direction(Direction.DOWN)
    elif action == InputAction.MOVE_LEFT:
        self.game_state = self.game_state.set_direction(Direction.LEFT)
    elif action == InputAction.MOVE_RIGHT:
        self.game_state = self.game_state.set_direction(Direction.RIGHT)
    elif action == InputAction.TOGGLE_PAUSE:
        # 迭代 1 占位：仅置 _pause_hint_shown=True（HUD 显示"按 P = 暂停（迭代 2）"）
        # **迭代 1 不调 game_state.toggle_pause()**
        self._pause_hint_shown = True


def _dispatch_over(self, action: InputAction) -> None:
    """GAME_OVER 态分发。R3-7：删除 QUIT 分支（主循环外层已先 break）。"""
    if action == InputAction.RESTART:
        self._new_game(self._difficulty)
```

### 4.5 节拍推进（_tick，R3-8 循环内重读 tick_ms）

```python
def _tick(self, dt_ms: int) -> None:
    """PLAYING 态累加节拍；循环内逐拍重读 tick_ms（R3-8）；OVER 自动转 GAME_OVER。"""
    assert self.screen == AppScreen.PLAYING
    assert self.game_state is not None
    self._tick_accumulator_ms += dt_ms
    while True:
        tick_ms = self.game_state.snapshot().tick_ms  # R3-8：每拍重读，吃食加速即时生效
        if self._tick_accumulator_ms < tick_ms:
            break
        self._tick_accumulator_ms -= tick_ms
        self.game_state = self.game_state.step()
        if self.game_state.status == GameStatus.OVER:
            self.screen = AppScreen.GAME_OVER
            self._pause_hint_shown = False
            break
```

```python
# menu.py — R3-2 形参收窄，仅依赖 pygame + Difficulty 枚举；不读 App 内部字段
def draw_menu(
    surface: pygame.Surface,
    title_font: pygame.font.Font,
    body_font: pygame.font.Font,
    difficulty: Difficulty,
) -> None:
    bg = (18, 18, 24)
    surface.fill(bg)

    title = title_font.render("Snake GUI v2.0.0", True, (255, 255, 255))
    surface.blit(title, (surface.get_width() // 2 - title.get_width() // 2, 100))

    lines = [
        ("按 1 键 = 简单", Difficulty.EASY),
        ("按 2 键 = 普通", Difficulty.MEDIUM),
        ("按 3 键 = 困难", Difficulty.HARD),
    ]
    for i, (text, diff) in enumerate(lines):
        color = (255, 210, 90) if diff == difficulty else (200, 200, 210)
        surf = body_font.render(text, True, color)
        surface.blit(surf, (surface.get_width() // 2 - surf.get_width() // 2, 220 + i * 36))

    # R3-1 任意键提示统一文案：Enter / 空格 / 其他键 全部能开始
    hint = body_font.render("Enter / 空格 / 其他键 开始", True, (200, 200, 210))
    surface.blit(hint, (surface.get_width() // 2 - hint.get_width() // 2, 400))

    quit_hint = body_font.render("Q 退出", True, (160, 160, 170))
    surface.blit(quit_hint, (surface.get_width() // 2 - quit_hint.get_width() // 2, 440))


def draw_game_over(
    surface: pygame.Surface,
    title_font: pygame.font.Font,
    body_font: pygame.font.Font,
    score: int,
) -> None:
    surface.fill((18, 18, 24))
    big = title_font.render("Game Over", True, (255, 90, 90))
    surface.blit(big, (surface.get_width() // 2 - big.get_width() // 2, 150))

    line = body_font.render(f"最终得分：{score}", True, (230, 230, 240))
    surface.blit(line, (surface.get_width() // 2 - line.get_width() // 2, 240))

    hint = body_font.render("R 重开    Q 退出", True, (200, 200, 210))
    surface.blit(hint, (surface.get_width() // 2 - hint.get_width() // 2, 320))
```

### 4.9 状态机图（R3-1 任意键 START 统一）

```
       ┌────────┐ Enter/空格/未映射键/方向键         ┌──────────┐
       │  MENU  │ ───────────────────────────▶ │ PLAYING  │
       │ (app   │   START (R3-1 屏态兜底)       │ (节拍     │
       │ 自绘)  │                                  │  step)    │
       └────────┘                                  └──────────┘
           ▲                                              │
           │  R 键 (RESTART)                              │ status==OVER
           │                                              │ (INV-2 自动转)
           │                                              ▼
           │                                        ┌──────────┐
           └─────────────────────────────────────── │ GAME_OVER│
                       _new_game(diff)                │ (app 自绘)│
                                                      └──────────┘

       任意态：Q/ESC → QUIT  → _drain_events 返回含 QUIT
                            → 主循环 'if QUIT in actions: break'
                            → finally renderer.shutdown()
```

### 4.10 实现注意点

1. **无全局变量**：app 状态全部在 `App` 实例字段，UT 可通过构造多个 `App` 实例隔离测试。
2. **pygame 副作用隔离**：`pygame.init()` / `pygame.quit()` 调用次数在 UT 中通过 fake pygame 模块统计（详见 §6.2）。
3. **不直接读 game_state 内部字段**：所有访问走 `snapshot()`；修改走 `set_direction` / `step`（返回新对象）。
4. **不直接读 gui-renderer 私有属性**：仅 `Renderer((W,H), skin=DEFAULT_SKIN)` 构造 + `init/shutdown` + `render(snap, hud)` + 读 `skin` property；自绘菜单/结束画面走 `pygame.display.get_surface()`（R3-2）。
5. **不引入 `time.sleep`**：所有延迟靠 `clock.tick_busy_loop(fps_cap)` + `_tick_accumulator_ms`。
6. **不 import platform_storage**：迭代 1 不调 `get_user_data_dir()` / `HighScoreStore`（对齐迭代边界）。
7. **不写任何文件**：迭代 1 进程不创建任何磁盘文件（无 log、无 config、无存档）。
8. **退出码约定**：0 正常 / 1 app 异常 / 2 图形环境不可用（NFR-03 最小集）。
9. **HUD `status_label` 必填**：renderer 第 2 行 `Status: ...` 必读，缺则 AttributeError；`_STATUS_LABEL[snap.status]` 在三种状态均有值。
10. **renderer.skin 只读**：迭代 1 仅 `DEFAULT_SKIN`，**不调** `set_skin`（gui-renderer iter-1 无此方法，迭代 3 接入）。
11. **`_drain_events` 是 None→START 的唯一转换点**（R3-1 全文统一）：`_map_event` 不感知屏态；`_dispatch_*` 收到的 None 不可能（已被 drain 兜底完）。
12. **CJK 字体走 `match_font` 回退链**（R3-12）：避免 Linux 下中文渲染成豆腐块；菜单提示/HUD 都受影响。

### 5.5 鲁棒性 / 韧性

| 场景 | 处理 |
|------|------|
| 图形环境缺失 | `Renderer.init()` 抛 `RenderError` → `GraphicsUnavailableError` → 退出码 2 + 人类可读 stderr + shutdown 兜底（R3-15） |
| 同一帧多事件 | `_drain_events` 返 list；主循环按序处理；QUIT 优先 break |
| 反向输入 | 透传到 `core.set_direction`；core 内静默忽略（长度 ≥2）/ 放行（长度 1）（对齐 FR-02） |
| 撞墙/撞身 | `core.step` 返回 `status=OVER`；`_tick` 检测后自动转 `GAME_OVER`（INV-2） |
| 关窗 | `pygame.QUIT` 事件 → `QUIT` action → 主循环 break → `renderer.shutdown()` |
| OVER 态继续按方向键 | `_dispatch_playing` 在 OVER 屏不会被调用（已转 GAME_OVER），无副作用 |
| Q/ESC 任意态 | `_map_event` 统一映射 `QUIT` action；主循环检测后 `_running=False` → break |
| 节拍漂移 | `_tick_accumulator_ms` 用累加 + while 循环 + **循环内重读 tick_ms**（R3-8），吃食加速即时生效 |
| 配置非法（fps_cap ≤ 0） | `AppConfig.__post_init__` 抛 `ConfigError`；`main()` 捕获后 stderr + 退出码 1 |
| MENU 态访问 game_state | INV-7：`_render` 在 MENU / GAME_OVER 态不调 `renderer.render`，避免 `None.snapshot()` 崩 |
| 中文字体缺失 | `_load_cjk_font` 走 `match_font` 回退链，全失败 → SDL 默认字体（不崩，文字可能为 □，符合"基础功能可用"基线；迭代 4 完善字体打包） |

### 5.6 错误处理矩阵（R3-9 InvalidStateError 修订）

| 错误情形 | 行为 |
|----------|------|
| `Renderer.init()`（内部 `pygame.init()`）失败 | `RenderError`（runtime error） → 包装为 `GraphicsUnavailableError` → 退出码 2 + shutdown 兜底（R3-15） |
| `Renderer.__init__` 校验失败（window_size 不合规） | 同上 |
| 构造 `App(fps_cap=0)` | `ConfigError`（`__post_init__` 校验） |
| 构造 `App(window_w < min_window_w)` | `ConfigError`（迭代 1 默认值已合规，仅防 FO 误传） |
| `App.run()` 中 `core` 抛 `InvalidStateError` | **R3-9：理论不可达（INV-1/2 保护），不包装；UT 覆盖不触发**。迭代 1 真发生 → 视为 bug，FAIL 由上半部巡检兜底 |
| `App.run()` 中未捕获异常 | 兜底 `except Exception` → stderr traceback + 退出码 1（迭代 4 收敛为更友好提示） |
