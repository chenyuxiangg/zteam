## 0. 范围与依赖

- **被测对象**：`game_core` 包（Point / Direction / Difficulty / GameStatus / Snake / Food / Snapshot / GameState / spawn_food / DIFFICULTY_PARAMS / InvalidStateError）
- **测试驱动**：pytest 9.x（与框架设计 §1 一致）；运行时零第三方依赖（NFR-05）
- **隔离策略**：RNG 注入 `random.Random(seed)` 实现确定性；模块不依赖文件系统/网络；无 GUI/SDL 初始化
- **用例编号**：`IT-game-core-1-{序号}`，与整体测试方案 §2.3 编号体系一致
- **优先级映射**：P0 = 玩法闭环/发布阻塞；P1 = 鲁棒性边界；P2 = 接口契约细节

## 2. 用例详情（关键 P0）

### IT-game-core-1-01：初始构造

**前置**：注入 `rng=Random(42)`，网格 20×15，难度 MEDIUM。
**步骤**：构造 `GameState(width=20, height=15, difficulty=Difficulty.MEDIUM, rng=rng)`。
**预期**：
- `len(snake) == 3`（INV-1）
- `direction == Direction.RIGHT`
- `score == 0`、`status == GameStatus.RUN`
- `food.pos not in snake.body`（INV-2）
- 蛇身 = `[(10,7),(9,7),(8,7)]`（居中朝右，W//2=10, H//2=7）

### IT-game-core-1-09：撞墙结束

**前置**：默认 20×15 MEDIUM 状态，蛇初始朝右。
**步骤**：连续 step 4 次（蛇头 x 从 10 → 14），第 5 次 step（蛇头预期到 x=15，越界）。
**预期**：
- 第 5 次 step 后 `status == GameStatus.OVER`
- `snake.body`、`food.pos`、`score` 与 step 前一致（INV-4）

### IT-game-core-1-10：撞自身结束

**前置**：构造 5×5 网格 + 固定 seed，初始蛇 3 节朝右。
**步骤**：通过多次 set_direction + step 形成 U 形蛇身，使下一步新头撞非尾身段。
**预期**：
- `status == GameStatus.OVER`
- `score` 不变（未吃食）

### IT-game-core-1-11：撞尾（不吃食）不结束

**前置**：构造 5×5 网格 + 固定 seed。
**步骤**：构造出蛇身使下一步新头恰好 = 旧尾坐标，且本 tick 不吃食。
**预期**：
- `status == GameStatus.RUN`（v1 一致行为）
- 蛇身"让行"：旧尾消失，新头占位

### IT-game-core-1-22：非法网格 < 4

**前置**：传入 width<4 或 height<4。
**步骤**：分别构造 `GameState(3, 3, MEDIUM, rng=...)`、`GameState(3, 15, MEDIUM, rng=...)`、`GameState(20, 3, MEDIUM, rng=...)`。
**预期**：均抛 `ValueError`（INV-7）。

### IT-game-core-1-29：端到端 100 步回归

**前置**：20×15 MEDIUM，固定 seed。
**步骤**：连续 step 100 次，每步记录 (score, length, status)。
**预期**：
- 任意 step k：`length - 3 == score`（每节长度+1 = 1 分）
- 任意 step k：`food.pos not in snake.body`（INV-2）
- 蛇身节点 4-邻接（INV-1）
