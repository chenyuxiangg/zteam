## 关键验证点

- **构造**：初始 3 节蛇居中朝右、食物不在蛇身、score=0、status=RUN
- **移动**：step 蛇头前进 1 格、蛇尾移除、不修改 self（纯函数性）
- **输入合并**：pending 隔离、step 一次性消费；多次 set_direction 取最后一次
- **反向禁止**：长度 ≥2 反向静默忽略；长度 1 反向生效（架构特例）
- **幂等**：set_direction(同方向) 返回值 == self.snapshot
- **吃食**：score+1、长度+1、新食物用同 rng 在非蛇身格随机生成（重复 20 次验证）
- **撞墙**：蛇头越界 → status=OVER，蛇身/食物/得分不变（INV-4）
- **撞自身**：新头与非尾身段重叠 → status=OVER
- **撞尾（不吃食）**：新头 = 旧尾且不吃食 → 不结束，蛇身让行（v1 行为一致）
- **撞尾（吃食）**：新头 = 旧尾且吃食 → status=OVER（v1 行为一致）
- **OVER 保护**：OVER 后 step / set_direction 抛 InvalidStateError
- **snapshot**：字段一致、tick_ms == difficulty.base_tick_ms、frozen 不可变
- **网格下限**：< 4 抛 ValueError；4×4 下限构造成功、初始蛇身全部在界内
- **接口契约**：Direction dx/dy/opposite 配对、Point 值对象（相等/哈希/frozen）、Difficulty 三档 base_tick_ms、property 走 DIFFICULTY_PARAMS 单一数据源
- **spawn_food 鲁棒**：5×5 全屏填蛇 → RuntimeError
- **100 步端到端回归**：score 与 length 同步（每节长度+1 = 1 分）、食物不在蛇身、蛇身节点 4-邻接
- **零 GUI 依赖**：无 pygame/pyinstaller/tkinter 等 import（NFR-05）
- **语法兼容 3.8**：所有 game_core/*.py AST 解析通过（无 PEP 604 / 内置泛型下标）
- **GameStatus**：迭代 1 不暴露 PAUSED 入口（无 toggle_pause 方法）
