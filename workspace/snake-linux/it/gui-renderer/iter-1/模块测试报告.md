## 关键验证点

- **首帧渲染**：蛇 3 节 + 食物（填充 + outline）+ 背景填充 + HUD 5 行全部正确；蛇头颜色 = `DEFAULT_SKIN.snake_head`，蛇身 = `snake_body`；食物像素坐标 = `(PLAYFIELD_X + 15*CELL_SIZE, PLAYFIELD_Y + 7*CELL_SIZE)` = `(376, 264)`；蛇头像素 = `(256, 264)`
- **蛇身长度 N**：draw.rect 对蛇节调用恰好 N 次（参数化 1/3/5/8 全过）
- **食物渲染**：填充 1 次（width=0）+ outline 1 次（width=1），颜色与 DEFAULT_SKIN 一致
- **HUD 文本**：5 行（Score/High/Length/Difficulty/Status），HIGH 始终 hud_accent 强调；Status=OVER 用 hud_accent 高亮，Status=RUN/PAUSED 用 hud_text
- **背景**：screen.fill 调用 1 次，颜色 = `DEFAULT_SKIN.background`
- **fps 采样**：每次 render 后 samples +1；连续 150 次 render 后容量稳定在 120（deque maxlen）；样本 < 20 时 P95 降级为 mean；空样本 P95/fps 都为 0
- **网格→像素**：cell(0,0)/(5,3)/(19,14) 三组映射正确
- **构造校验**：窗口过小 / 颜色越界 / window_size 非 tuple / cell_size 等非正整数 均抛 RenderError
- **render 异常**：snapshot=None / snake_body 空 → RenderError；render 前未 init → AssertionError
- **生命周期**：init / shutdown 各自幂等；`__enter__` 返回 self；`__exit__` 即使 render 抛异常也调 shutdown（异常安全）
- **frozen 契约**：Color / HudData / Skin frozen dataclass，赋值抛 FrozenInstanceError
- **静态检查**：renderer 不导入 socket/urllib/http/requests/httpx/aiohttp（NFR-06）；renderer 不 import game_core（NFR-05 职责分离，仅 UT 构造时显式 from game_core import 类型作为契约验证）
- **跨模块契约**：真实 game_core.Snapshot（含 Point / Difficulty / GameStatus）作为 render 入参正常工作，HUD 文本含 "MEDIUM" / "RUN"
