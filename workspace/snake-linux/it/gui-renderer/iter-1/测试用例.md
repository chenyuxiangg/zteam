## 0. 范围与依赖

- **被测对象**：`gui_renderer` 包（`Renderer` / `Color` / `Rect` / `Skin` / `HudData` / `FpsMetric` / `RenderError` / `SkinNotFoundError` + 模块常量 `DEFAULT_SKIN` / `WINDOW_WIDTH` / `WINDOW_HEIGHT` / `HUD_HEIGHT` / `CELL_SIZE` / `GRID_COLS` / `GRID_ROWS`）
- **依赖模块**：`game_core.Snapshot` / `Point` / `Difficulty` / `GameStatus`（构造真实快照作为 renderer 入参，跨模块契约验证）
- **测试驱动**：pytest 9.x；运行时通过 fake_pygame 模块替换 `pygame`（设计 §4.2 可测性 + 框架 §1 选型）
- **隔离策略**：`SDL_VIDEODRIVER=dummy` 默认 headless；fake_pygame 在 conftest 中注入；无文件系统/网络
- **用例编号**：`IT-gui-renderer-1-{序号}`，与整体测试方案 §2.3 编号体系一致
- **优先级映射**：P0 = 渲染闭环/发布阻塞；P1 = 接口契约/鲁棒性；P2 = 体验细节

## 2. 用例详情（关键 P0）

### IT-gui-renderer-1-01：首帧渲染

**前置**：默认窗口 `(640, 480)`，DEFAULT_SKIN，蛇身 3 节 `(10,7)/(9,7)/(8,7)` 朝右，食物 `(15,7)`，HUD `(score=0, high_score=128, length=3, difficulty_label="MEDIUM", status_label="RUN")`。
**步骤**：调用 `renderer.render(snapshot, hud)`。
**预期**：
- 背景 `screen.fill` 调用 1 次，颜色 = `DEFAULT_SKIN.background`（FR-06）
- `pygame.draw.rect` 总调用 ≥ 3（蛇 3 节）+ 2（食物填充 + outline）= ≥ 5 次
- `font.render` 调用 5 次（HUD 5 行文本）
- 蛇节颜色：第 1 节 = `DEFAULT_SKIN.snake_head`；第 2/3 节 = `DEFAULT_SKIN.snake_body`
- 食物填充 = `DEFAULT_SKIN.food`，outline = `DEFAULT_SKIN.food_outline`（width=1）
- 蛇头像素位置 = `(PLAYFIELD_X + 10*CELL_SIZE, PLAYFIELD_Y + 7*CELL_SIZE)` = `(256, 192)`
- 食物像素位置 = `(PLAYFIELD_X + 15*CELL_SIZE, PLAYFIELD_Y + 7*CELL_SIZE)` = `(376, 192)`
- 无字符串残留断言（构造时清空 fake_pygame 调用记录）

### IT-gui-renderer-1-04：食物渲染（填充 + outline）

**前置**：蛇身 1 节 `(5,5)`，食物 `(10,10)`，DEFAULT_SKIN。
**步骤**：调用 `renderer.render(snapshot, hud)`。
**预期**：
- draw.rect 中 `(food_color, food_rect, 0)` 存在 1 次（填充）
- draw.rect 中 `(food_outline_color, food_rect, 1)` 存在 1 次（outline，width=1）
- food_rect = `(PLAYFIELD_X + 10*CELL_SIZE, PLAYFIELD_Y + 10*CELL_SIZE, CELL_SIZE-1, CELL_SIZE-1)`

### IT-gui-renderer-1-15：构造校验：窗口过小

**前置**：DEFAULT_SKIN。
**步骤**：`Renderer((100, 100))`（小于最小可玩尺寸）。
**预期**：抛 `RenderError`，错误信息含"小于最小可玩尺寸"。

### IT-gui-renderer-1-16：构造校验：skin 颜色越界

**前置**：自定义 `Skin(name="bad", background=Color(300,0,0), ...)`。
**步骤**：构造 `Renderer((640, 480), skin=bad_skin)`。
**预期**：抛 `RenderError`，错误信息含"越界 [0, 255]"。

### IT-gui-renderer-1-29：静态检查：renderer 无网络依赖（NFR-06）

**前置**：renderer 源码路径 `snake-linux/code/gui-renderer/iter-1/gui_renderer/`。
**步骤**：用 `ast` 解析所有 `.py` 文件，遍历 `Import` / `ImportFrom`，断言不出现 `socket` / `urllib` / `http` / `requests` / `httpx` / `aiohttp`。
**预期**：无匹配；断言消息含"NFR-06 无网络"。

### IT-gui-renderer-1-31：跨模块契约

**前置**：从 `game_core` 构造真实 `Snapshot(snake_body=(Point(10,7), Point(9,7), Point(8,7)), food=Point(15,7), score=0, length=3, status=GameStatus.RUN, difficulty=Difficulty.MEDIUM, tick_ms=160)`。
**步骤**：调用 `renderer.render(snapshot, HudData(...))`。
**预期**：render 正常完成，无 TypeError / AttributeError；蛇节数 = 3，食物存在，HUD 文本含 "MEDIUM" / "RUN"。
