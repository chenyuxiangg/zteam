## 0. 范围与依赖

- **被测对象**：`gui_renderer` 包（迭代 3 增量）
  - 新增类型：`InterpolationState`（frozen，prev_food 可为 None；修订 P2-1）
  - 新增 Skin 字段：`cell_gap: int` / `food_pattern: str` / `snake_pattern: str`（默认值兼容迭代 1；hud_shadow 已删除）
  - 新增常量：`DARK_SKIN` / `COLORBLIND_FRIENDLY_SKIN` / `SKIN_REGISTRY` / `CELL_SIZE_MIN` / `MIN_PLAYABLE_W` / `MIN_PLAYABLE_H`
  - 新增/变更异常：`SkinNotFoundError(name, available)` 结构化构造（修订 P3-1）
  - 新增 `Renderer` 方法：`set_skin(name)` / `handle_resize(w, h)` / `skin_names()` / `current_skin_name` / `render(snap, hud, *, interp=None)` 增量参数
  - 新增构造参数：`enable_high_dpi: bool = True`（pygame.SCALED，修订 P1-1 方案③）
- **依赖模块**：`game_core.Snapshot` / `Point` / `Difficulty` / `GameStatus`（同迭代 1，跨模块契约继续生效）
- **测试驱动**：pytest 9.x；运行时通过 fake_pygame 模块替换 `pygame`（沿用迭代 1 conftest 模式）
- **隔离策略**：`SDL_VIDEODRIVER=dummy` headless；fake_pygame 在 conftest 中注入；无文件系统/网络
- **用例编号**：`IT-gui-renderer-3-{序号}`，与整体测试方案 §2.3 编号体系一致
- **优先级映射**：P0 = 渲染闭环/发布阻塞；P1 = 接口契约/鲁棒性/视觉/缩放；P2 = 体验细节
