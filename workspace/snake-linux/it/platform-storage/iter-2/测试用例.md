## 0. 范围与依赖

- **被测对象**：`platform_storage` 包（get_user_data_dir / HighScoreStore / StorageError / atomic_write_json）
- **测试驱动**：pytest + unittest 双兼容（与设计 §7.2 一致）；测试侧依赖仅 pytest/pepect；被测代码运行时零第三方依赖（NFR-05）
- **隔离策略**：`tmp_path`（pytest）注入 `HighScoreStore(path=)`，**不污染用户真实数据目录**；平台路径用例用 `monkeypatch.setattr` 隔离 `sys.platform`/`os.environ`，避免污染全局状态
- **用例编号**：`IT-storage-2-{序号}`，与整体测试方案 §2.3 编号体系一致
- **优先级映射**：P0 = 核心持久化/发布阻塞；P1 = 鲁棒性边界；P2 = 体验细节

## 2. 用例详细规范

> 规范：每个用例含【前置条件】【步骤】【预期】【关联代码位置】；断言消息必须含需求编号（测试套件框架 §3.3）。

### IT-storage-2-01 三平台用户数据目录定位
- **关联需求**：FR-13、NFR-07
- **优先级**：P0
- **类型**：路径/集成
- **前置条件**：`tmp_path` 隔离目录；monkeypatch `platform_storage.paths.sys.platform` 与 `os.environ`
- **步骤**：
  1. monkeypatch `sys.platform = "win32"`、`os.environ["APPDATA"] = str(tmp_path / "AppData/Roaming")` → 调用 `get_user_data_dir()`，断言路径等于 `{tmp_path}/AppData/Roaming/SnakeGui` 且目录已存在
  2. monkeypatch `sys.platform = "win32"`、清空 `APPDATA`、monkeypatch `Path.home() -> tmp_path / "home"` → 调用 `get_user_data_dir()`，断言路径等于 `{tmp_path}/home/AppData/Roaming/SnakeGui`
  3. monkeypatch `sys.platform = "darwin"`、monkeypatch `Path.home() -> tmp_path / "home"` → 调用 `get_user_data_dir()`，断言路径等于 `{tmp_path}/home/Library/Application Support/SnakeGui`
  4. monkeypatch `sys.platform = "linux"`、`os.environ["XDG_DATA_HOME"] = str(tmp_path / "xdg")` → 调用 `get_user_data_dir()`，断言路径等于 `{tmp_path}/xdg/SnakeGui`
  5. monkeypatch `sys.platform = "linux"`、删除 `XDG_DATA_HOME`、monkeypatch `Path.home() -> tmp_path / "home"` → 调用 `get_user_data_dir()`，断言路径等于 `{tmp_path}/home/.local/share/SnakeGui`
- **预期**：五种场景全部断言通过；目录均自动创建
- **关联代码**：`platform_storage/paths.py:24-48`
