## 2. 用例明细

### IT-game-app-4-01：真实装配（SDL dummy 真实 Renderer）

**前置**：`SDL_VIDEODRIVER=dummy`、`SDL_AUDIODRIVER=dummy`；PYTHONPATH 含四个 code 目录；`XDG_DATA_HOME=tmp_path`（隔离真实用户目录）。
**步骤**：
1. `app = App(AppConfigV3(enable_high_dpi=True))`（构造后断言无副作用：`_renderer is None`、`game_state is None`、pygame 未 init）；
2. `app._init_pygame()`；
3. 断言 `app._renderer` 是 `gui_renderer.Renderer` 实例且 `init()` 已执行（内部 `_screen` 非 None）；
4. 断言 `app._storage` 是 `platform_storage.HighScoreStore` 实例；`app._high_score == app._storage.load()`（INV-12）；
5. 断言 `app._hidpi_degraded is False`（dummy 驱动下 SCALED 可用，不触发降级）。

**预期**：真实 pygame（SDL dummy）+ 真实 Renderer + 真实 HighScoreStore 全链路装配成功；构造无副作用（R3-10）；INV-12/18 成立。

### IT-game-app-4-02：真实渲染闭环（三态）

**前置**：同 4-01，已 `_init_pygame()`。
**步骤**：
1. `_new_game(Difficulty.HARD)` → 断言 `screen == PLAYING`、`game_state.snapshot()` 7 字段齐全；
2. 循环 60 次：`_tick(16)` + `_render()` —— **真实绘制**（dummy surface），断言全程不抛异常、`screen` 仍 PLAYING（未提前 OVER）；
3. `_dispatch_playing(TOGGLE_PAUSE)` → `_render()`（PAUSED 态真实绘制 + 暂停遮罩）；
4. `_dispatch_paused(TOGGLE_PAUSE)` → `_render()`（恢复 PLAYING）；
5. 强制 `game_state` 到 OVER（或 `_tick` 推进到撞墙）→ `_render()`（GAME_OVER 态真实绘制）。

**预期**：真实渲染链路三态全部可绘制，不抛任何异常（FR-06/07 真实成立）。
> 说明：本用例是**真实集成试金石**——gui-renderer iter-3 IT 全部走 fake 桩（`fake_pg.draw.calls`），从未在真实 pygame 下执行过 `render()`；自定义 `Color` dataclass 与 pygame API 的兼容性只有本用例能暴露。

### IT-game-app-4-03：真实事件驱动主循环

**前置**：同 4-01。
**步骤**：
1. `pygame.event.post(pygame.event.Event(pygame.QUIT))`；
2. `rc = app.run()`；
3. 断言 `rc == 0`；断言 `pygame.display.get_init() is False`（shutdown 已执行，INV-5）。

**预期**：真实 pygame 事件队列驱动主循环，QUIT 正常退出码 0；`Renderer.shutdown()` 兜底执行（INV-5）。

### IT-game-app-4-04：真实存储集成（INV-12/13）

**前置**：`tmp_path` 隔离；`app._storage = HighScoreStore(tmp_path/"highscore.json")`（注入后 `_init_pygame` 跳过 create_storage）；SDL dummy。
**步骤**：
1. `_init_pygame()` → `_high_score == 0`（空文件 load 返 0）；
2. `_new_game(Difficulty.MEDIUM)` → 断言 game_state 已注册 score_callback；
3. 手动触发回调 `cb(50)` → 断言 `_high_score == 50`（INV-13 直接写实例字段）+ `highscore.json` 文件实存且 JSON 内容含 50（真实落盘）；
4. 新 App 实例（同 tmp_path）`_init_pygame()` → 断言 `_high_score == 50`（重启加载一致，INV-12）；
5. `_dispatch_menu(RESET_HIGHSCORE)` → 断言 `_high_score == 0` + 文件 JSON 归零。

**预期**：真实 HighScoreStore 落盘/加载/重置链路与 app 装配一致（FR-13 真实 IO）。

### IT-game-app-4-05：进程级退出码 0

**前置**：真实子进程；`python -m game_app`（PYTHONPATH 四 code 目录 + SDL dummy + XDG 隔离）。
**步骤**：
1. 子进程内：`_init_pygame` 后 `pygame.event.post(QUIT)` → `main()` 返回 0；
2. 断言子进程退出码 0、stderr 无异常输出。

**预期**：真实进程正常退出码 0（FR-11/IT-app-4-02）。

### IT-game-app-4-06：进程级退出码 2（图形环境不可用）

**前置**：真实子进程；`SDL_VIDEODRIVER=invalid_driver`（SDL 无法创建窗口）。
**步骤**：
1. 子进程跑 `main()`；
2. 断言退出码 == 2；断言 stderr 含 `"[错误]"` 与 `"建议"`（人类可读，NFR-03）；
3. 断言 stderr 不含 `"Traceback"`。

**预期**：图形环境不可用 → 退出码 2 + suggestion 写入 stderr（INV-17/G4-2）。

### IT-game-app-4-07：进程级退出码 3（用户数据目录不可写）

**前置**：真实子进程；`XDG_DATA_HOME=<只读目录>`（chmod 500 的 tmp 目录，或 monkeypatch `create_storage` 抛 OSError 的等价进程内脚本）。
**步骤**：
1. 子进程内 monkeypatch `game_app.storage.create_storage` 抛 `OSError("permission denied")` → 跑 `main()`；
2. 断言退出码 == 3；断言 stderr 含 `"用户数据目录不可写"` 与 `"建议"`。

**预期**：存储不可用 → 退出码 3（iter-4 新增，G4-2）+ suggestion 写入 stderr（INV-17）。

### IT-game-app-4-08：stderr 可读性（无裸 traceback）

**前置**：复用 4-06/4-07 两路子进程的 stderr 捕获。
**步骤**：
1. 收集两个错误路径的完整 stderr；
2. 断言均不含 `"Traceback"` / `"File \""`（无堆栈泄露，NFR-03 最小集）。

**预期**：可预见错误全部人类可读，无裸 traceback（NFR-03）。

### IT-game-app-4-09：退出卫生（1 秒内 + 无残留）

**前置**：复用 4-05 子进程。
**步骤**：

**预期**：任意时刻退出 1 秒内干净结束、无残留进程（IT-app-4-02/FR-11）。
