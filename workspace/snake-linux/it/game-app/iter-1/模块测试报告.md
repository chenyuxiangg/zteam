## 关键验证点

### 1. 构造 / 接口契约
- **R3-10 构造无副作用**：`App()` 后 `_renderer is None`，`screen=MENU`，`game_state is None`，未调 `pygame.init()` / `display.set_mode`
- **AppConfig**：默认 640×480/60FPS/min 512×472；frozen；非法 fps_cap / window 抛 ConfigError
- **AppScreen**：仅 MENU/PLAYING/GAME_OVER 三态（PAUSED 迭代 2 才有）
- **InputAction**：完整 11 值（QUIT/START/MOVE_4/TOGGLE_PAUSE/RESTART/SELECT_3）

### 2. 输入映射（_map_event 不感知屏态）
- WASD + 方向键 → MOVE_*
- K_q/K_ESCAPE/pygame.QUIT → QUIT
- K_p → TOGGLE_PAUSE / K_r → RESTART
- K_1/2/3 → SELECT_EASY/MEDIUM/HARD
- 未映射 KEYDOWN → None

### 3. R3-1 _drain_events 屏态兜底
- **MENU 态**：None → START；方向键 → START；保留键（SELECT_*/TOGGLE_PAUSE/RESTART/QUIT）透传
- **PLAYING 态**：None 不过滤（返 []）；方向键 → MOVE_*（透传）
- **GAME_OVER 态**：未映射键被过滤（None 透传）；R 键 → RESTART

### 4. 状态机迁移
- **INV-3**：`SELECT_*` 在 PLAYING 屏态被 `_dispatch_playing` 忽略，难度游戏中不可改
- **INV-1**：`_dispatch(MOVE_*)` 后 `game_state is not old_state`（set_direction 返新对象）
- **撞墙/撞身 → OVER**：`_tick` 自动检测 `status=OVER` 并转 `screen=GAME_OVER`
- **INV-3 OVER 后 set_direction 抛 InvalidStateError**（R3-9 不包装，理论不可达）

### 5. 节拍（R3-8 + INV-4）
- `_tick(170)` HARD 100ms → step 1 次，累加器剩 70
- `_tick(500)` HARD → step 5 次，累加器归零
- `_tick(0)` 不调 step；`_tick(160)` MEDIUM 恰好调 1 次
- `_tick(500+140)` MEDIUM → 累加器先 20（500-3×160），后 0（+140 追跑 1 次）

### 6. HUD（R3-11 共享 snap + INV-6）
- `_build_hud(snap)` 返 HudData（5 字段：score/high_score/length/difficulty_label/status_label）
- `high_score == 0`（int，非字符串）
- difficulty_label 中文："简单/普通/困难"
- status_label 与 game_state.status 对应

### 7. 渲染分发（R3-2 / R3-11）
- **MENU 态**：调 `pygame.display.get_surface()` + `menu.draw_menu`；**不**调 `renderer.render`
- **GAME_OVER 态**：调 `get_surface` + `menu.draw_game_over`；**不**调 `renderer.render`
- **PLAYING 态**：调 `renderer.render(snap, hud)` 一次；`game_state.snapshot()` 也只调 1 次（R3-11）
- **R3-2 不读私有**：spy `_screen` 访问次数=0（修改属性为抛错也无副作用）

### 8. 退出 / 错误处理（INV-5 / R3-15）
- `run()` 触发 QUIT → `Renderer.shutdown` → `pygame.quit` 至少 1 次
- 退出码 2 路径（display.set_mode 抛错）：返回 2 + stderr 可读提示 + 兜底 shutdown 仍调用 1 次
- AppConfig 非法 fps_cap / window 直接抛 ConfigError（`__post_init__` 校验）

### 9. R3-7 死代码清理
- App 类无 `_quit` 方法
- `_dispatch_menu`/`_dispatch_over` 内不写 `self._running=False`（主循环外层先 break）

### 10. 端到端
- **任意键开始**：MENU 态注入未映射 KEYDOWN → `_drain_events` 返 `[START]` → dispatch 开局
- **主链路**：选 MEDIUM → START → 撞墙（4×4）→ R 重开 → 再撞墙 → QUIT → 退出码 0

### 11. 静态检查（NFR-05/06）
- **零网络 import**：`game_app/*.py` 无 `socket`/`urllib`/`http`/`requests`/`ftplib`/`smtplib`
- **Python 3.8 兼容**：AST 扫描无 PEP 604（X | Y）/ 内置泛型下标（list[X]/dict[X,...]）
- **零音效 import**：无 `pygame.mixer`/`pygame.music`/`pygame.sndarray`

### 12. 跨迭代协同
- game-core iter-2 公开 API 适配：GameState 全关键字构造、Snapshot 字段齐（含 tick_ms）
- gui-renderer iter-1 公开 API 适配：HudData 5 字段齐、DEFAULT_SKIN 渲染
- App 装配：构造 → 选难度 → 开局 → snapshot 不抛
