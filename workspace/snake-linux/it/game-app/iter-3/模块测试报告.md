## 端到端集成路径

### IT-game-app-3-18：MENU 切皮肤 → START → PLAYING 走插值

1. MENU 注入 `[K_RIGHT]` → `_drain_events` → `set_skin("dark")` 调 1 次 + `_skin_index==1`
2. 注入 `[K_RETURN]` → `_drain_events` 返回 `[START]` → `_dispatch` → `_new_game(MEDIUM)` → `screen==PLAYING`
3. `_tick(160)` 推一拍（HARD 需 _tick=100；MEDIUM tick_ms=160）→ `_prev_snap` 已存（step 前）
4. `_tick_accumulator_ms=80` + `_render()` → `Renderer.render(snap, hud, interp=InterpolationState(alpha=0.5, prev_snake_body, prev_food))`
5. PLAYING 注入 `[K_LEFT]` → `_drain_events` 返回 `[MOVE_LEFT]`（屏态透传） + `set_skin.assert_not_called()`（FR-10 对局不中断）

### IT-game-app-3-19：PLAYING 中 VIDEORESIZE 不中断插值

1. `_tick(100)` 建立 `_prev_snap` + `_render` 走 interp
2. 注入 `[VIDEORESIZE(900, 700)]` → `Renderer.handle_resize(900, 700)` 调 1 次
3. `_screen == PLAYING` 不变（INV-15）
4. `_render` 继续走 `interp=`（非 None）

### IT-game-app-3-20：完整链路 MENU→PLAYING→PAUSED→缩放→GAME_OVER→MENU

MENU 选 HARD → START → PLAYING → ← 透传 MOVE_LEFT → _tick → P→PAUSED → 缩放（handle_resize(800,600) + 屏态不变） → P→PLAYING → monkeypatch step 返 OVER → GAME_OVER（_prev_snap=None） → BACKSPACE → MENU（game_state=None，INV-7 重置）

全部状态机迁移、屏态同步方案 A、INV-7 重置、缩放兜底（INV-15）、OVER 清空 `_prev_snap` 均通过。

### 关键 fixture
- `app` / `app_in_playing` / `app_in_paused` / `app_in_game_over`：monkeypatch `app_mod.create_storage`（直接 import 绑定）+ `app_mod.Renderer` + `_init_pygame()`

- `_set_events(app, events)`：直接给 `fake_pygame.event.get.return_value` 打补丁
