## 0. 范围与依赖

- **被测对象**：`game_app` 包（`App` / `AppConfig` / `AppScreen` / `InputAction` / `AppError` / `GraphicsUnavailableError` / `ConfigError` / `StorageUnavailableError` / `_load_cjk_font` / `menu.draw_menu` / `menu.draw_game_over` / `menu.draw_pause_overlay` / `storage.create_storage` / `_DIFFICULTY_LABEL` / `_STATUS_LABEL`）
- **协作模块契约**（IT 仅通过公开 API 触发，不重测内部）：
  - `game-core.iter2.GameState`：`set_direction` / `step` / `snapshot` / `toggle_pause`（RUN↔PAUSED；OVER 抛 InvalidStateError；PAUSED→RUN 清 pending_direction）/ `score_callback` 参数
  - `gui-renderer.iter1.Renderer`：`render(snap, hud)`（iter-2 game-app 只用基础 render，不调 set_skin/handle_resize/render(interp=)）
  - `platform-storage.iter2.HighScoreStore`：`load()` / `save(score)` / `reset()`
- **测试驱动**：pytest 9.x；pygame 副作用通过 fake 模块桩化（沿用 `code/game-app/iter-1/tests/test_game_app/conftest.py` 的 `fake_pygame` + `fake_storage` + `FakeEvent` 模式）
- **隔离策略**：所有 pygame 调用走 fake；`Renderer` 在大多数用例中被 `MagicMock` 替换；事件序列通过 `fake.event.get.return_value` / `side_effect` 注入；`HighScoreStore` 通过 `fake_storage` MagicMock 或 `tmp_path` 真实 IO
- **用例编号**：`IT-game-app-2-{NN}`，与整体测试方案 §2.3 编号体系对齐（其中 IT-app-2-01~03 已定义）
- **优先级映射**：P0 = 暂停/继续/失焦/最高分联动（FR-12/FR-13 发布阻塞）；P1 = 输入分发/HUD 数据源/状态机边界；P2 = 字体回退/常量化边界
- **不重复测**：反向禁止/撞墙/撞身/吃食等核心玩法逻辑由 `game-core` IT 与 UT 覆盖，本模块 IT 仅验证 app 装配与状态机协作；存储原子写/损坏恢复/平台目录定位由 `platform-storage` IT 覆盖，本模块 IT 仅验证 app 端持久化调用链路

## 2. 用例明细

### IT-game-app-2-01：难度选择（沿用 iter-1 INV-3）

**前置**：`fake_pygame` + `fake_storage` 注入；构造 `App()`。
**步骤**：
1. 注入事件 `[K_1]`（SELECT_EASY）→ `_drain_events` → `_dispatch_menu`；
2. 注入事件 `[K_RETURN]`（未映射→START）→ `_drain_events` → `_dispatch_menu` → `_new_game`；
3. 断言 `app._difficulty == Difficulty.EASY`、`app.screen == AppScreen.PLAYING`、`app.game_state is not None`；
4. 注入事件 `[K_2]`（SELECT_MEDIUM，PLAYING 态）→ `_drain_events` → `_dispatch_playing`（SELECT_* 无分支）→ 断言 `_difficulty` 不变。
**预期**：难度入口在 PLAYING 态不可改（INV-3）；与 iter-1 已 PASS 行为一致。

### IT-game-app-2-02：暂停快捷键与失焦自动暂停（G2-1/G2-4）

**前置**：`fake_pygame.key.get_focused.return_value = True`；`app_in_playing`（HARD 难度）。
**步骤**：
1. 注入 K_p 事件 → `_drain_events` → `_dispatch_playing(TOGGLE_PAUSE)`；
2. 断言 `app.screen == AppScreen.PAUSED`、`app.game_state.status == GameStatus.PAUSED`；
3. 注入 K_p 事件 → `_dispatch_paused(TOGGLE_PAUSE)`；
4. 断言 `app.screen == AppScreen.PLAYING`、`app.game_state.status == GameStatus.RUN`；
5. 设 `fake.key.get_focused.return_value = False`；注入无事件（仅 UNFOCUS 内部信号）→ `_drain_events` 应追加 UNFOCUS → `_dispatch_playing(UNFOCUS)`；
6. 断言 `app.screen == AppScreen.PAUSED`；
7. 设 `fake.key.get_focused.return_value = True`；注入 K_RETURN（未映射→PLAYING 态透传 None）→ 断言 screen 仍为 PAUSED（恢复不自动）。
**预期**：P/失焦触发 PAUSED，恢复需用户按 P（避免误触闪烁）；屏态同步方案 A（INV-11）。

### IT-game-app-2-03：最高分联动（G2-2/G2-3/G2-6）

**前置**：`fake_storage` 注入；`fake_storage.load.return_value = 42`。
**步骤**：
1. 构造 `App()` → `_init_pygame()` → 注入 fake_storage；
2. 断言 `app._high_score == 42`（storage.load() 覆盖）；
3. 注入 K_h（RESET_HIGHSCORE）→ `_dispatch_menu(RESET_HIGHSCORE)`；
4. 断言 `fake_storage.reset.call_count == 1`、`app._high_score == 0`；
5. 注入 K_RETURN（START）→ `_new_game(HARD)` → 断言回调已注册；
6. 手动触发回调：模拟吃食得分 `cb(100)`；
7. 断言 `app._high_score == 100`、`fake_storage.save.call_count == 1`、`fake_storage.save.call_args == (100,)`。
**预期**：_init_pygame 加载 → H 重置 → 吃食回调同步高分 + 落盘（G2-3 INV-13 P0-2）。

### IT-game-app-2-06：ESC 独立 action + GAME_OVER 覆盖为 BACK_TO_MENU

**前置**：`fake_pygame`；构造 `App()`；进入 GAME_OVER 态（手动 `app.screen = AppScreen.GAME_OVER` + `app.game_state = dataclasses.replace(game_state, status=GameStatus.OVER)`）。
**步骤**：
1. 注入 K_ESCAPE 事件 → `_map_event(ev)` 断言返回 `InputAction.ESCAPE`（不返 QUIT）；
2. 调 `_drain_events()` → 断言返回列表含 `InputAction.BACK_TO_MENU`（GAME_OVER 覆盖）；
3. 调 `_dispatch_over(BACK_TO_MENU)`；
4. 断言 `app.screen == AppScreen.MENU`、`app.game_state is None`（INV-7 重置）。
**预期**：ESC 与 Q 区分（P1-2 修订）；GAME_OVER 态 ESC 转 BACK_TO_MENU 而非 QUIT 直通。

### IT-game-app-2-08：GAME_OVER 态 BACK_TO_MENU（G2-7）

**前置**：`app_in_game_over`（dataclasses.replace 强制 status=OVER）。
**步骤**：
1. 注入 K_BACKSPACE → `_drain_events`；
2. 断言 actions 列表含 `BACK_TO_MENU`；
3. `_dispatch_over(BACK_TO_MENU)`；
4. 断言 `app.screen == AppScreen.MENU`、`app.game_state is None`。
**预期**：Backspace 直返 BACK_TO_MENU（_map_event 不经屏态覆盖）；重置 INV-7。

### IT-game-app-2-10：_dispatch_paused 全分支

**前置**：`app_in_paused`（HARD，已 toggle 到 PAUSED）。
**步骤**（参数化）：
1. `_dispatch_paused(InputAction.TOGGLE_PAUSE)` → 断言 `screen == PLAYING`、`game_state.status == RUN`；
2. 重新进 PAUSED → `_dispatch_paused(InputAction.MOVE_UP/DOWN/LEFT/RIGHT)` 各 → 断言 game_state 不变、`screen == PAUSED`；
3. 重新进 PAUSED → `_dispatch_paused(InputAction.UNFOCUS)` → 断言 screen 仍 PAUSED（PAUSED 态再失焦无操作）。
**预期**：PAUSED 态仅响应 TOGGLE_PAUSE；MOVE_* 忽略；UNFOCUS 忽略。

### IT-game-app-2-11：_dispatch_playing 全分支

**前置**：`app_in_playing`。
**步骤**：
1. `_dispatch_playing(InputAction.MOVE_UP)` → 断言 `game_state.pending_direction == Direction.UP`；
2. `_dispatch_playing(InputAction.MOVE_RIGHT)` → 断言 `pending_direction == RIGHT`（仅最后一次生效，INV-4）；
3. `_dispatch_playing(InputAction.TOGGLE_PAUSE)` → 断言 `screen == PAUSED`、`game_state.status == PAUSED`；
4. 重新进 PLAYING → 设 fake.key.get_focused=False → 注入空事件 → `_drain_events` 追加 UNFOCUS → `_dispatch_playing(InputAction.UNFOCUS)` → 断言 screen PAUSED。
**预期**：方向/MOVE/PAUSE/UNFOCUS 全部派发正确；屏态同步方案 A 单点（INV-11）。

### IT-game-app-2-12：_run_loop 跳过 PAUSED 态 _tick

**前置**：`app_in_paused`；monkeypatch `app._tick` 为 spy。
**步骤**：
1. 手动模拟主循环内一次"if screen==PLAYING then _tick(dt_ms)"判断；
2. screen==PAUSED → 跳过；
3. 断言 spy 调用列表为空。
**预期**：INV-10 入口保证——PAUSED 态 `_tick` 不进入；累加器/step 不推进。

### IT-game-app-2-14：_render PAUSED 路径

**前置**：构造带 MagicMock renderer 的 paused app（mock renderer + mock fonts）。
**步骤**：

2. 调 `app._render()`；
3. 断言 `mock_renderer.render.call_count == 1`（最后一帧渲染）；
4. 断言 `spy.call_count == 1`（遮罩叠加）；

**预期**：G2-5 暂停遮罩叠加在最后一帧之上；play_pause_overlay 走 `pygame.display.get_surface()`（R3-2 不读 renderer 私有）。

### IT-game-app-2-15：draw_pause_overlay 内容

**预期**：遮罩自绘契约——半透明矩形 + 居中 PAUSED + 提示文字（R3-12 CJK 字体走 _menu_body_font）。

### IT-game-app-2-16：_init_pygame 构造 HighScoreStore（G2-2）

### IT-game-app-2-20：_new_game 注册 score_callback（G2-3 P0-2）

**前置**：`fake_storage`（load=0）；构造 App；注入 fake_storage。
**步骤**：
1. 调 `app._new_game(Difficulty.MEDIUM)`；
2. 断言 `app.game_state._score_callback is not None`（core 字段）；
3. 调 `app.game_state._score_callback(50)`；
4. 断言 `app._high_score == 50`（INV-13 P0-2：直接写实例字段）；
5. 断言 `fake_storage.save.call_count == 1`（max(50, load=0)=50 入盘）；
