# 功能模块分工表：snake-linux v2.0.0（snake-gui）

> SE 排期依据 · 与 `modules.json` 完全一致 · 需求规格：snake-gui-r1（approved）

## 模块清单

| 模块 | 类型 | 职责 | 依赖模块 | 承载需求 | 迭代计划 |
|------|------|------|----------|----------|----------|
| game-core | 基础平台 | 玩法核心纯逻辑：蛇身模型、移动/吃食/碰撞/反向禁止、难度档位参数（简单250ms/普通160ms/困难100ms 基线）+加速曲线、运行状态机（run/paused/over）、得分与最高分判定。零 GUI 依赖，可脱离界面 UT（NFR-05） | 无 | snake-gui（子集：FR-01~05/12 逻辑） | 1, 2 |
| platform-storage | 中间件 | 跨平台用户数据目录定位、最高分/偏好 JSON 持久化、原子写防损坏（异常退出不丢）、重置入口支撑（FR-13/NFR-06/07） | 无 | snake-gui（子集：FR-13） | 2 |
| gui-renderer | 中间件 | Pygame 画面渲染（蛇/食物/背景/HUD）、平滑插值动画（FR-07）、皮肤系统 ≥3 套（经典/深色/色盲友好，FR-10）、窗口等比缩放自适应（FR-09）、高分屏清晰（NFR-04） | game-core | snake-gui（子集：FR-06~10） | 1, 3 |
| game-app | 上层应用 | 主入口与事件循环、输入映射（WASD/方向键/P/ESC）、界面流程（开始/难度选择/暂停/继续/结束/重开/退出）、皮肤切换、可读错误提示（NFR-03）、PyInstaller 三平台打包与发布物（FR-14~16） | game-core, gui-renderer, platform-storage | **snake-gui（主体）** | 1, 2, 3, 4 |

## 需求 → 模块映射

- snake-gui → **game-app**（上层应用，需求主体；dispatch 落盘于此）
- 支撑关系：game-core（玩法逻辑）← gui-renderer（渲染）← game-app（装配）；platform-storage（持久化）→ game-app（最高分展示/重置）

## 迭代计划（SE 排期）

| 迭代 | 目标 | 模块 | 出口验收 |
|------|------|------|----------|
| 1 | 最小闭环·可玩 | game-core（玩法闭环+难度参数）、gui-renderer（基础渲染）、game-app（主循环/输入/开始-结束-重开-退出） | 规格验收 1（玩法闭环）、4（控制流程）可自动化验证 |
| 2 | 体验功能 | game-core（暂停状态机+加速曲线）、platform-storage（最高分持久化）、game-app（暂停继续/最高分展示重置；**难度选择 UI 已在迭代 1 完成**，不重复实现，见 game-app 设计 R2-14） | 验收 2（难度分级）、4（暂停/最高分） |
| 3 | 视觉增强 | gui-renderer（平滑动画+皮肤系统+窗口缩放）、game-app（皮肤切换 UI） | 验收 3（GUI 呈现） |
| 4 | 交付打磨 | game-app（三平台打包/错误提示/性能调优）、全模块回归、用户指南+发布物 | 验收 5（开箱即用）、6（性能）、7（兼容矩阵） |

**迭代串行依据**：1→2→3→4 依依赖顺序推进（玩法 → 体验 → 视觉 → 交付）；迭代内模块并行，经 game-core snapshot 接口联调。
