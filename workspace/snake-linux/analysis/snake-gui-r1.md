## 背景与目标

**结论先行**：snake-linux 已有终端版 v1.0.0（已 released），验证了玩法闭环与交付链路；本需求是**形态升级 + 体验扩展**——从终端字符界面升级为美观的图形界面，覆盖范围从单一 Linux 终端扩展到 Windows / macOS / Linux 三大桌面平台，交付形态从"源码运行"升级为"下载即玩"，并在经典玩法之上**纳入难度分级、暂停/继续、最高分持久化、皮肤系统**（用户已拍板，见 §0）。

- **业务背景**：终端版面向开发者/技术用户，启动依赖 Python 环境与终端；普通用户无法直接使用。本次要做"全新形态的版本，不再局限在终端"（需求原文），目标是让贪吃蛇成为**普通用户可安装、可运行、可玩**的产品级 GUI 游戏。
- **目标**：交付一个跨 Windows/macOS/Linux 的图形界面贪吃蛇游戏，满足四个核心诉求——界面美观、操作流畅、开箱即用、跨平台，并按用户拍板扩展难度分级、暂停/继续、最高分持久化、皮肤系统四项能力。

## 功能需求（FR，MECE 分解）

分组维度：按**用户旅程**（游戏玩法 → 界面呈现 → 控制与流程 → 安装交付）分组，组间互不重叠，合则覆盖"下载 → 玩 → 退出"全过程。玩法基线继承终端版 v1.0.0（经典贪吃蛇），本需求在此之上叠加已拍板的新能力（FR-05/10/12/13），不改变经典规则本身。

### 2.1 游戏玩法核心

| 编号 | 功能点 | 描述 | 优先级 | 验收标准 |
|------|--------|------|--------|----------|
| FR-01 | 经典玩法闭环 | 蛇按节拍自动前进；方向控制（WASD 与方向键 ↑↓←→）；吃食物蛇身 +1、得分 +1；撞墙或撞自身结束 | 高 | 不操作输入时蛇每节拍前进 1 格；方向键响应 ≤ 1 个节拍；吃 N 个食物后长度 = 初始 + N、分数 = N |
| FR-02 | 反向移动禁止 | 蛇不能 180° 掉头撞向自身（如向右移动时按左键无效） | 高 | 向右移动中按 A/←，蛇保持向右，不因反向自杀而结束 |
| FR-03 | 食物生成 | 开局生成 1 个食物；被吃后在 1 个节拍内于新位置重生；食物不与蛇身重叠 | 高 | 食物被吃后 1 个节拍内出现新食物，新食物坐标与蛇身所有坐标均不同 |
| FR-04 | 结束判定与画面 | 蛇头撞墙/撞自身 → 游戏结束，显示最终得分与"重开/退出"选项 | 高 | 触发结束条件后游戏停止移动，结束画面稳定显示得分与重开/退出入口 |
| FR-05 | **难度分级**（R-01 新增） | 开局可选难度档位，档位决定基础移动节拍与加速曲线；**游戏中不可切换档位**（防规避） | 高 | 三档（简单/普通/困难）均存在且开局可选；档位间节拍差异可感知（困难档节拍 ≤ 简单档节拍的 50%，量化见 NFR-01）；各档位均可完成完整玩法闭环（FR-01~04 验收项全过） |

> 难度参数说明：三档建议基线节拍为 简单 250ms / 普通 160ms / 困难 100ms（每格），随蛇身增长可逐步加速（加速曲线为玩法参数，具体数值由 SE 实现阶段确定，**验收以"档位间存在可感知差异且各档可玩通"为准**，不锁定具体毫秒值）。

### 2.2 界面呈现（形态升级核心）

| 编号 | 功能点 | 描述 | 优先级 | 验收标准 |
|------|--------|------|--------|----------|
| FR-06 | 图形界面渲染 | 以图形（非字符）方式渲染游戏画面：蛇身、食物、背景、HUD 均为图形元素，无终端字符残留 | 高 | 游戏画面中不存在字符/文本终端式渲染（文字标签除外）；窗口标题、图标完整 |
| FR-07 | 平滑动画 | 蛇的移动带平滑过渡（逐帧插值移动而非整格跳变），视觉连贯不闪烁 | 高 | 蛇移动过程中无整格跳变、无画面闪烁/撕裂；观感连续（对齐 NFR-01） |
| FR-08 | 界面美观基线（R-09 确认） | 视觉要素达到"美观"基线：配色主题、清晰的蛇/食物辨识度、整洁的 HUD 布局 | 高 | 蛇与食物在任意主题下可清晰区分；HUD（得分/最高分/长度）固定位置、字号清晰；整体观感无粗糙感（验收维度 = r1 建议的"平滑动画 + 清晰辨识度 + 整洁 HUD + 多主题"，用户已认可） |
| FR-09 | 窗口自适应 | 窗口可调整大小，游戏画面等比缩放适配；存在最小可玩尺寸 | 中 | 拖拽改变窗口大小后画面等比缩放无变形、无裁切；小于最小尺寸时给出提示而非画面错乱 |
| FR-10 | **皮肤系统**（R-08 新增） | ≥3 套皮肤/主题（含**深色主题**与**色盲友好配色方案**），可在设置/开始界面切换；皮肤仅改变配色与外观，不影响玩法 | 中 | 至少 3 套皮肤可切换；色盲友好方案下蛇/食物/背景可清晰区分（不以颜色为唯一区分手段）；切换后立即生效且当前对局不中断 |

### 2.3 游戏控制与流程

| 编号 | 功能点 | 描述 | 优先级 | 验收标准 |
|------|--------|------|--------|----------|
| FR-11 | 开始/重开/退出流程 | 有开始界面（按任意键/点击开始）；结束后可重开新局或退出；任意时刻可退出游戏 | 高 | 启动后进入开始界面；结束后重开可立即开始新局；任意时刻退出进程在 1 秒内干净结束、无残留进程 |
| FR-12 | **暂停/继续**（R-02 确定） | 游戏中可暂停与继续（P 键/ESC；窗口失焦自动暂停为加分项） | 中 | 暂停时画面定格、节拍停止；继续后从暂停处恢复（蛇位/得分/长度不变）；暂停期间方向输入不生效 |
| FR-13 | **最高分持久化**（R-03 新增） | 本地保存历史最高分，重启不丢；HUD 或开始界面展示；提供"重置最高分"入口 | 中 | 单局得分超过历史最高分时更新保存；重启游戏后最高分仍显示；重置后归零；数据仅存本地（对齐 NFR-06），异常退出不损坏历史记录 |

### 2.4 安装与交付（开箱即用）

| 编号 | 功能点 | 描述 | 优先级 | 验收标准 |
|------|--------|------|--------|----------|
| FR-14 | 免预装直接运行（R-06 确定形态） | 交付形态 = **三平台各自免安装单文件可执行**（Windows .exe / macOS .app / Linux 可执行文件），用户下载后**无需预装任何第三方运行时/框架**即可运行 | 高 | 在无 Python/Node/Java 等预装环境的干净三平台机器上，下载后直接启动成功 |
| FR-15 | 跨平台运行一致 | 同一版本（v2.0.0）在 Windows / macOS / Linux 三平台可运行，玩法与核心体验一致 | 高 | 三平台各跑通 FR-01~FR-13 全部验收项；键位、玩法、界面布局无平台差异 |
| FR-16 | 用户指南 | 交付 README/用户指南：下载与运行方式、键位表、难度/皮肤/暂停等操作说明、平台差异说明、已知限制 | 中 | 文档存在且五节齐全（含新增功能操作说明）；按文档在三平台可复现启动（对齐 FR-14/FR-15） |

## 非功能需求（NFR）

| 编号 | 类别 | 需求 | 可验证指标 |
|------|------|------|-----------|
| NFR-01 | 性能 | 操作流畅、无卡顿（"流畅"的量化基线；含难度档位差异） | 默认节拍 ≤ 200ms；从按键到蛇转向生效的输入延迟 ≤ 1 个节拍；渲染帧率 ≥ 60 FPS，P95 帧时间 ≤ 25ms（渲染能力受限环境可降级，但不得卡顿超过 1 秒）；困难档节拍 ≤ 简单档节拍的 50% |
| NFR-02 | 性能 | 资源占用轻量 | 运行时内存 ≤ 300MB、CPU 占用 ≤ 10%（单核，空闲画面），作为回归指标 |
| NFR-03 | 可用性 | 失败场景提示友好 | 图形环境缺失/驱动异常/平台不兼容等可预见失败输出人类可读错误提示而非崩溃静默/裸 traceback |
| NFR-04 | 兼容性 | 平台覆盖矩阵 | Windows 10/11、macOS 12+（Intel 与 Apple Silicon）、主流 Linux 桌面发行版（Ubuntu 22.04+/Fedora/Arch 之一）行为一致；高分屏（HiDPI）下界面清晰不模糊 |
| NFR-05 | 可维护性 | 代码职责分离 | 游戏逻辑 / 渲染 / 输入处理分层，GUI 层与平台解耦；核心玩法逻辑可脱离 GUI 独立测试（供 UT 使用，含难度档位参数化逻辑） |
| NFR-06 | 安全与合规 | 本地单机、无网络行为（R-05 收紧） | **无任何网络上传/下载**；不收集用户数据；本地持久化数据仅限游戏进度类（最高分等），无广告/无捆绑安装 |
| NFR-07 | 交付完整性 | 发布物规范 | 发布包含版本号（v2.0.0）、各平台包校验和（SHA256）、发布说明；安装/运行路径不写系统目录（便携式） |

## 边界与约束

### 做什么
- 三平台（Windows/macOS/Linux）桌面 GUI 贪吃蛇，经典玩法 + 难度分级（FR-05）；
- 图形界面（非字符）、平滑动画、美观基线、皮肤系统（FR-06~FR-10）；
- 暂停/继续、最高分持久化（FR-12/FR-13）；
- 开箱即用：三平台免安装单文件可执行，下载即玩；
- 交付用户指南与发布物规范。

### 不做什么（已按用户拍板明确）
- 不做移动端（Android/iOS）、不做 Web 浏览器版（"跨平台"限定为三大桌面平台）；
- **不做联网对战/排行榜/分享/任何联网能力**（R-05 拍板，本地单机）；
- **不做音效/音乐**（R-04 拍板）；
- 不改动终端版 snake-linux（独立交付，互不影响）；
- **不做技术选型与实现方案论证（GUI 框架/语言/打包工具选型均属 How，由 SE/实现阶段决策，本规格只固化需求约束）**。

### 约束
- 玩法规则与终端版 v1.0.0 保持一致（差异仅形态与已拍板新增能力）；
- "开箱即用"硬约束：**三平台免安装单文件可执行、用户侧零预装、零配置**（R-06 拍板）；
- 三平台同一版本号、行为一致（FR-15）；
- **本需求以 v2.0.0 独立交付**（R-07 拍板，独立于终端版 v1.0.0）；
- 难度档位游戏中不可切换（防规避，FR-05）。

## 验收标准

> 供后续 UT/IT/ST 使用；每条可独立验证。标注（R-xx）为新增/收紧项。

1. **玩法闭环（FR-01~FR-04）**：自动化测试覆盖——方向控制、吃食增长、食物不重叠、反向禁止、撞墙/撞身结束，全部通过；
2. **难度分级（FR-05，R-01）**：三档开局可选；档位间节拍差异可感知（困难 ≤ 简单 50%）；各档位完整对局可玩通；
3. **GUI 呈现（FR-06~FR-10）**：启动后为图形界面且无字符渲染残留；蛇移动平滑无跳变；窗口缩放画面不变形；≥3 套皮肤（含深色/色盲友好）可切换且辨识清晰；三平台截图对比核心布局一致；
4. **控制流程（FR-11~FR-13）**：开始→游玩→结束→重开/退出全流程可走通；暂停/继续功能符合 FR-12（R-02）；最高分持久化符合 FR-13（R-03）——重启保留、可重置、仅本地；退出 1 秒内无残留进程；
5. **开箱即用（FR-14~FR-16）**：三平台免安装单文件可执行（R-06），干净机器（无预装运行时）下载即运行；按指南可复现；
6. **性能（NFR-01~02）**：帧率 ≥ 60 FPS、输入延迟 ≤ 1 节拍、资源占用在指标内（性能脚本实测留档）；
7. **兼容矩阵（NFR-04）**：Windows 10/11、macOS 12+（双架构）、Ubuntu 22.04+ 各跑通 1~5 轮完整对局。

## 假设与待确认点

### 已确认决定（用户 2026-08-13 拍板，无需再确认）
难度分级纳入本轮；暂停/继续纳入；最高分本地持久化纳入；不做音效；不做联网/排行榜；交付形态 = 三平台免安装单文件可执行；版本号 v2.0.0；皮肤系统纳入（含色盲友好/深色主题）；美观基线按 r1 建议认可。

### 假设（默认成立，若不同意请指出）
- **A-01**：单机本地游戏，无任何网络能力（已拍板 R-05，此处仅为留档）；
- **A-02**：不做音效/音乐（已拍板 R-04，留档）；
- **A-03**：难度档位 = 三档（简单/普通/困难），游戏中不可切换；档位具体节拍/加速曲线数值由 SE 实现阶段确定（验收以档位间可感知差异为准）；
- **A-04**：皮肤系统起步 ≥3 套（经典 / 深色 / 色盲友好），具体美术方案由实现阶段设计；
- **A-05**：最高分持久化提供"重置"入口（FR-13 已按提供编写）；
- **A-06**："跨平台" = Windows/macOS/Linux 三大桌面平台，不含移动端与 Web；
- **A-07**：玩法与终端版 v1.0.0 一致（经典贪吃蛇规则），本需求只升级形态并叠加已拍板新能力。

### 待确认点（剩余低风险细节，请评审时顺带拍板）
- **Q-01**：难度三档命名"简单/普通/困难"是否认可？（默认认可）
