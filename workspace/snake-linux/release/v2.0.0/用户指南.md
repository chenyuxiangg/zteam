# 用户指南：Snake GUI v2.0.0

> 跨平台贪吃蛇游戏 · Windows / macOS / Linux 三平台 · 免安装单文件可执行
> 版本：v2.0.0 · 发布：2026-08-15

---

## 1. 下载与运行

### 1.1 下载

- **Linux**：`snake-gui-linux-x86_64`（约 25MB）
- **Windows**：`snake-gui-windows-x86_64.exe`（约 25MB）
- **macOS**：`snake-gui.app`（universal2，Intel + Apple Silicon，约 30MB）

下载后请用 `SHA256SUMS` 文件校验完整性（见第 8 节）。

### 1.2 运行方式

**Linux**

```bash
chmod +x snake-gui-linux-x86_64
./snake-gui-linux-x86_64
```

若提示缺少 SDL2 运行库：

```bash
# Ubuntu / Debian
sudo apt install libsdl2-2.0-0
# Fedora
sudo dnf install SDL2
# Arch
sudo pacman -S sdl2
```

**Windows**：双击 `snake-gui-windows-x86_64.exe` 运行。若 SmartScreen 提示"未知发布者"，点"更多信息"→"仍要运行"。

**macOS**：双击 `snake-gui.app` 运行。若 Gatekeeper 提示"无法验证开发者"，在"系统设置 → 隐私与安全性"中点"仍要打开"。

### 1.3 系统要求

| 平台 | 最低版本 | 备注 |
|------|---------|------|
| Linux | Ubuntu 22.04+ / Fedora 36+ / Arch（最新） | 需 SDL2 运行库 |
| Windows | Windows 10 | 推荐 10 / 11 |
| macOS | macOS 12 (Monterey) | 推荐 13+ |

**无需预装 Python / Node / Java 等任何运行时。**

## 3. 难度

三档难度在**开局时选择**，游戏中不可切换（需返回菜单重新选）：

| 难度 | 基础节拍 | 说明 |
|------|---------|------|
| 简单 | 250ms / 格 | 蛇速慢，适合新手 |
| 普通 | 160ms / 格 | 标准体验 |
| 困难 | 100ms / 格 | 挑战极限 |

档位间差异显著（困难档节拍 ≤ 简单档 50%）。蛇身增长后会自动加速（加速曲线）。

## 5. 暂停 / 最高分

- **暂停/继续**：游戏中按 P 暂停，再按 P 继续；暂停时画面定格、节拍停止；**窗口失焦会自动暂停**。
- **最高分**：单局得分超过历史最高分时自动保存；HUD 与结束画面展示；按 **H** 重置归零。数据仅存本地用户目录，不联网。

## 6. 平台差异

| 平台 | 字体 | 最高分数据目录 |
|------|------|---------------|
| Linux | 内置字体优先，系统字体回退 | `~/.local/share/snake-gui/highscore.json` |
| Windows | 内置字体 | `%APPDATA%\snake-gui\highscore.json` |
| macOS | 系统字体 | `~/Library/Application Support/snake-gui/highscore.json` |

## 7. 已知限制

- **未签名 / 未公证**：Windows SmartScreen / macOS Gatekeeper 首次运行会警告（手动确认即可）。
- **macOS < 12**：未充分测试，可能存在兼容性问题。
- **中文显示**：依赖内置字体（SourceHanSansCN-Regular.otf，OFL 协议）；字体损坏时回退系统字体，中文可能显示为方框。
- **HiDPI**：默认启用高分屏缩放；显卡驱动不支持时自动降级（可能略糊）。
- **窗口缩放**：依赖 pygame VIDEORESIZE 事件；个别显卡驱动异常时可能无法拖拽。

## 8. 校验与 FAQ

**校验完整性**：在下载目录执行

```bash
# Linux / macOS
sha256sum -c SHA256SUMS
# Windows（PowerShell）
Get-FileHash -Algorithm SHA256 <文件名>
```

**FAQ**

- **Q：Linux 启动报 "error while loading shared libraries: libSDL2"？**
  A：安装 SDL2 运行库（见 1.2）。
- **Q：最高分怎么不保存？**
  A：检查用户数据目录是否可写；异常退出不影响已保存的历史（原子写防损坏）。
- **Q：能不能在游戏中途改难度？**
  A：不能（防规避设计）；返回菜单重新选择即可。
- **Q：蛇会不会 180° 掉头自杀？**
  A：不会，反向输入被忽略（经典规则）。
