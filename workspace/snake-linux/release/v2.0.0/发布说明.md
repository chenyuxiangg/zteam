## 1. 一句话总结

交付跨 Windows / macOS / Linux 三平台的图形界面贪吃蛇（免安装单文件可执行），支持难度分级、暂停/继续、最高分持久化、3 套皮肤（含色盲友好），覆盖需求规格全部验收项，质量与安全评审**通过**。

## 2. 变更清单（FR/NFR 全覆盖）

- **玩法闭环**（FR-01~04）：方向控制 / 吃食增长 / 食物不重叠 / 反向禁止 / 撞墙撞身结束
- **难度分级**（FR-05）：三档（简单 250ms / 普通 160ms / 困难 100ms），游戏中不可切换
- **图形界面**（FR-06~09）：图形渲染 / 平滑插值动画 / 窗口等比缩放 / 美观基线
- **皮肤系统**（FR-10）：3 套（经典 / 深色 / 色盲友好），对局中切换不中断
- **控制流程**（FR-11~13）：开始 / 重开 / 退出（1 秒内干净结束）；暂停 / 继续（含失焦自动暂停）；最高分本地持久化（原子写防损坏 + 重置）
- **开箱即用**（FR-14~16）：三平台免安装单文件可执行（PyInstaller）；跨平台一致；用户指南
- **非功能**（NFR-01~07）：性能 / 资源占用 / 错误提示友好 / 兼容矩阵 / 职责分离 / 本地单机零网络 / 发布物规范

## 4. 已知限制（非阻塞，随发布环境闭环）

1. **三平台矩阵人工项**：Windows 10/11、macOS 12+ 双架构的真机完整对局（1~5 轮）需发布环境执行（PyInstaller 不支持交叉打包）；本机仅 Linux 实测。
2. **真窗口性能/观感**：ST 性能数值基于 SDL dummy（headless），仅留档；真窗口判定归发布环境人工矩阵（与 IT-4-14 同口径）。
3. **干净机器免预装验收**：需独立干净环境执行（ST-01 本机以资产齐备 + 启动链路近似）。
4. **文档陈旧项（非产品缺陷）**：`it/game-app/iter-4/模块测试报告.md` 头部仍为「结论 FAIL / MTO-4-01 open」（MTO 复测 close 后未回写报告头）。实际状态已由 ST 回归（game-app iter-4 28 passed）、问题单 close 记录、模块 it_passed 状态三方确认闭环，不影响发布。
5. **历史迭代测试白名单**：game-app iter-1（4 条）/ iter-3（1 条）白名单失败为测试代码版本错位（代码目录为「活目录」，断言旧快照），非产品回归。

## 5. 回滚方案

- **本版本为独立交付**（v2.0.0 与已 released 终端版 v1.0.0 互不影响），无需回滚旧版本即可撤下。
- **发布后发现问题**：撤销本版本发布物（删除 release 包），需求回到 `analyzing` 状态重新走流程（`change_request` 或新版本承载），不影响 v1.0.0 及流水线其他项目。
- **数据回滚**：最高分等本地数据仅存用户数据目录，版本回退不影响已存数据；`reset` 入口可随时归零。
