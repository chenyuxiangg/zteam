# Linux 终端版 Pac-Man

一个使用 Python 标准库 `curses` 实现的单机终端吃豆人。包含吃豆计分、能量豆反击、清豆过关、扣命/结算、四幽灵差异化 AI、暂停、输入缓冲与干净退出。

## 1. 环境与安装

- Linux 终端，建议 `xterm-256color` 或兼容终端
- 终端至少 80×24
- Python 3.8+
- 运行时无 pip 第三方依赖，`requirements.txt` 为空依赖声明

Ubuntu/Debian 通常自带 `curses`。若精简系统报 `_curses` 缺失：

```bash
sudo apt install python3-curses
```

本游戏不联网、不保存用户数据、不要求提升权限。

## 2. 运行

在本 README 所在目录执行：

```bash
python3 -m pacman
```

也可执行：

```bash
python3 pacman/main.py
# 或
python3 run.py
```

三个入口行为一致，推荐使用 `python3 -m pacman`。

非 TTY、地图文件错误或终端初始化失败时，程序会输出明确错误并返回非零退出码。终端尺寸不足时会在全屏界面提示当前尺寸，按任意键退出。

## 3. 键位

| 操作 | 键位 |
|---|---|
| 移动 | 方向键或 W/A/S/D |
| 暂停/恢复 | P |
| 退出 | q 或 Ctrl+C |

转向使用一个槽位的输入缓冲：直道上提前按下转向，到首个合法路口执行；更新的指令会覆盖旧指令。暂停时移动、模式计时和能量倒计时均冻结。

## 4. 玩法与计分

- 普通豆：10 分；能量豆：50 分。
- 吃能量豆后幽灵进入脆弱状态，最后 2 秒蓝/白闪烁。
- 同一能量周期内连续吃幽灵获得 200/400/800/1600 分，第五只起封顶 1600。
- 清空地图 216 颗豆进入下一关；地图与实体重置。
- 初始 3 命。撞到追逐/散开态幽灵会扣命并回出生点；重置后有 2 秒保护期。
- 命数归零显示最终分数、关卡和吃到的幽灵数，按任意键退出。
- 难度随关卡递增：幽灵基础速度提升（上限 0.98 格/tick），能量时间从 6 秒逐关缩短（下限 1 秒）。

## 5. 四幽灵 AI

目标格规则来自开发方案引用的 Pac-Man Dossier：

- Blinky（红/B）：直接追玩家；残豆进入 Elroy 阈值后加速，散开期也追击。
- Pinky（粉/P）：目标为玩家前方 4 格；朝上时保留街机原版额外左偏行为。
- Inky（青/I）：以玩家前方 2 格为轴，结合 Blinky 位置做向量翻倍，形成协同围堵。
- Clyde（橙/C）：距玩家至少 8 格时追击，近于 8 格时撤往自己的角落。

通常状态按 `SCATTER → CHASE` 节奏切换；模式切换强制掉头。吃能量豆进入随机游走的 `FRIGHTENED`；被吃后成为 `EYES` 返回鬼屋重生。

简化项（与开发方案 §8 一致）：Blinky 与其他幽灵一样从鬼屋内出生；Elroy/速度/出场阈值采用简化公式而非街机逐关全表。

## 6. 配置

```text
--map PATH       自定义地图文件
--ghosts 2|3|4   幽灵数量，默认 4
--lives 1..9     初始命数，默认 3
--no-color       禁用颜色，使用字符区分
--speed 0.5..2.0 全局移动倍率，默认 1.0
--level N        从第 N 关开始，默认 1
```

查看完整帮助：

```bash
python3 -m pacman --help
```

### 自定义地图格式

UTF-8 矩形文本，每行等宽。允许字符：

| 字符 | 含义 |
|---|---|
| `#` | 墙 |
| `.` | 普通豆 |
| `o` | 能量豆（至少 4 个） |
| 空格 | 空通道 |
| `P` | 玩家出生区（至少一个） |
| `H` | 鬼屋 |
| `-` | 鬼屋门（玩家不可通过） |
| `B/I/K/C` | 可选幽灵出生标记（不写时使用鬼屋格） |

地图必须至少 5×5、至少 100 颗豆，玩家通道和幽灵通道分别全连通；鬼屋必须由墙和门封闭。大地图需要相应更大的终端。非法地图会给出文件、行和列提示。

逻辑模块 `game/map/entities/ghost_ai` 不导入 curses，便于后续 test-developer 脱离终端测试。

## 8. 已知限制

- 仅支持 Linux/Unix curses 终端，不做 Windows、GUI、浏览器、联机与音效。
- 不保存最高分；结算只显示本局成绩。
- 终端运行中缩到 80×24 以下会显示尺寸提示并退出，不做动态布局缩放。
- 内置地图为 22×19，不是街机 28×31；可通过 `--map` 使用自定义尺寸。
- FRIGHTENED 的随机路线不保证复现；四幽灵常态目标规则为确定性。
