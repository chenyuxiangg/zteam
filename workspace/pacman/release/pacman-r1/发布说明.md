## 4. 安装与使用
- 安装（零 pip 依赖，纯标准库）：
  ```bash
  tar -xzf pacman-v1.0.0.tar.gz && cd pacman   # 解包后即安装完成
  # 极简发行版若报 ModuleNotFoundError: _curses：
  sudo apt install python3-curses              # Debian/Ubuntu；Alpine: apk add py3-curses
  ```
- 运行（在解包目录下）：
  ```bash
  python3 -m pacman        # 或 python3 run.py；终端需 ≥80×24
  ```
- 常用参数：`--ghosts 2|3|4`（幽灵数）、`--lives 1..9`、`--speed 0.5..2.0`、`--map <文件>`（自定义地图）、`--no-color`、`--log-ai`
- 卸载：删除解包目录即可（游戏无持久化文件、无系统级安装）。
- 详细说明见用户指南.md。

## 5. 已知限制与风险
1. **地图规格 22×19**（需求原文规格），非原版 28×31——因 31 行超出「≥80×24 完整显示」验收口径；可用 `--map` 加载自定义 28×31 地图（启动尺寸检查兜底）。
2. **Pinky/Inky 向上偏移 bug** 忠实复刻原版（Pac-Man Dossier 第四章）；不需要可一行改为修正版。
3. **Elroy 阈值 / 难度参数采用简化公式**，非原版全表；核心体验（玩家略快/残豆加速/难度递增）保持一致。
4. **Blinky 出生在鬼屋内**（简化），按出场规则立即出屋。
5. **不做最高分持久化**（Q7 默认）；结算仅显示本次得分。
6. **不支持 256 关级无限关卡**（原版整数溢出 kill screen 属街机缺陷，不做）。
7. **e2e_pty.py 默认地图路径问题**（test r1-review 意见 1，已登记）：系统层自动化需 `--map` 显式传绝对路径，否则默认相对路径在 chdir 后失效；逻辑层 194/194 不依赖此路径。建议 code r2 将 DEFAULT_MAP 改为基于 `__file__` 的绝对路径。
8. **README §9 自检命令 4（FR-10 验证）存在索引笔误**（`g[3]` 越界）：FR-10 的客观证据以测试套件 U-20（四目标互异，194 全绿中通过）为准；releaser 自检时已用修正索引的等价脚本复验通过。建议 code r2 修正 README 该命令。
9. **性能用例（P-01~P-03 FPS/响应/5 分钟）未做自动化断言**（已登记）：帧率 ≥10 FPS 由 tick=100ms + time.monotonic 设计保证；系统层 PTY 实测启动 0.07s、渲染正常。
10. **I-08（--log-ai 端到端格式比对）未自动化**：FR-10 差异已有 U-20 硬证；--log-ai 可复现维度待 r2 锁定格式后补。
