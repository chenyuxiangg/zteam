# pacman 用户指南（v1.0.0）

## 1. 简介

**pacman** 是运行于 Linux 终端的经典街机吃豆人（Pac-Man）人机对战游戏：你控制吃豆人吃掉迷宫中的所有豆子，同时躲避四只各有性格的幽灵（AI）追击；吃能量豆后可限时反击吃掉幽灵。纯 Python 标准库实现，**零第三方依赖**，解包即玩。

- 四幽灵差异化 AI：Blinky 直线追击（残豆加速 Elroy）、Pinky 前方预判拦截、Inky 协同围堵（最难预测）、Clyde 距离感知（近撤远追）
- 完整对局：吃豆得分（豆 10 分/能量豆 50 分）、能量豆限时脆弱（连吃 200/400/800/1600）、清豆过关、撞幽灵扣命、命尽结算
- 终端 ≥80×24 即可运行；退出后终端状态完全恢复

## 2. 安装

### 环境要求
- Linux 系统（Ubuntu/Debian 等；本版本在 Linux 5.15 + Python 3.11 实测）
- Python **≥3.8**（curses 为标准库内置，无需 pip 安装任何包）

### 安装步骤
```bash
# 1. 解包产品包
tar -xzf pacman-v1.0.0.tar.gz
cd pacman

# 2. 直接运行（无需任何 pip 命令）
python3 -m pacman
# 或：
python3 run.py
```

### 极简发行版（可选系统包）
若报 `ModuleNotFoundError: No module named '_curses'`，安装系统包：
```bash
sudo apt install python3-curses   # Debian/Ubuntu
# Alpine: apk add py3-curses
```

## 3. 快速开始

```bash
# 解包并启动默认对局
tar -xzf pacman-v1.0.0.tar.gz && cd pacman
python3 -m pacman
```
启动后 ≤3 秒内出现完整迷宫画面，即可用方向键或 WASD 开始移动。目标：吃掉全部 216 颗豆子过关；吃 `o`（能量豆）后幽灵变蓝，撞之可反吃。

## 4. 使用说明

### 4.1 键位
| 键 | 动作 |
|------|------|
| ↑ / W | 向上 |
| ↓ / S | 向下 |
| ← / A | 向左 |
| → / D | 向右 |
| P | 暂停 / 恢复 |
| Q | 退出 |
| Ctrl+C | 安全退出（终端状态自动恢复） |

> 方向键会被缓冲至下一个路口执行（容量 1，新指令覆盖旧指令），连续快速输入不丢失。

### 4.2 命令行参数
| 选项 | 默认 | 说明 |
|------|------|------|
| `--map PATH` | `data/map_classic.txt` | 自定义地图文件路径（格式见 4.4） |
| `--ghosts 2\|3\|4` | 4 | 幽灵数量（保留 Blinky，按 Pinky/Inky/Clyde 顺序取） |
| `--lives 1..9` | 3 | 初始命数 |
| `--level N` | 1 | 起始关卡 |
| `--speed 0.5..2.0` | 1.0 | 全局速度倍率（0.5 慢速演示 / 2.0 极速挑战） |
| `--no-color` | 关 | 关闭颜色（单色模式） |
| `--log-ai` | 关 | 输出 AI 行为日志到 stderr（每 tick 各幽灵目标格与方向） |

示例：
```bash
python3 -m pacman --ghosts 2 --lives 5 --speed 0.5 --log-ai
python3 -m pacman --map /path/to/custom_map.txt --no-color
```

### 4.3 对局规则速览
- 幽灵三态：追逐（CHASE）/散开（SCATTER）按时间表交替（首段 SCATTER 7s / CHASE 20s，随关卡递减），切换瞬间幽灵强制掉头；吃能量豆后全部进入脆弱（FRIGHTENED）态，最后 2 秒蓝白闪烁
- 出场规则：Pinky/Blinky 立即出；Inky 吃 30 豆出；Clyde 吃 60 豆出（随关卡递减）
- 连吃幽灵得分：200/400/800/1600，之后封顶 1600
- 过关：吃完全部豆子自动进入下一关（地图重置、难度递增）；命尽显示结算画面

### 4.4 自定义地图格式
纯文本文件，每行一个 tile 字符，**行宽必须一致**：
| 字符 | 含义 |
|------|------|
| `#` | 墙（不可通行） |
| `.` | 普通豆（10 分） |
| `o` | 能量豆（50 分，使全部幽灵脆弱） |
| `-` | 鬼屋门（仅幽灵可通行） |
| `H` | 鬼屋内部（仅幽灵可通行） |
| `P` | 玩家出生区（玩家可通行） |
| ` `（空格） | 通道 |

加载时强制校验（不通过则报错退出，不进入游戏）：
1. 连通性：以玩家出生点为起点 BFS，全部豆子格可达；
2. 鬼屋通道：鬼屋必须有门，且门邻接一个玩家可达格；
3. 多规格适用：任意规格地图统一执行上述判定。

## 5. 常见问题

| 现象 | 原因与解决 |
|------|-----------|
| 启动即报错退出，无画面 | 终端尺寸 <80×24 → 放大终端窗口；或非真实终端（如管道重定向）→ 请直接在终端运行 |
| `ModuleNotFoundError: No module named '_curses'` | 极简发行版缺 curses 系统包 → `sudo apt install python3-curses`（Alpine: `apk add py3-curses`） |
| 启动后立即报「地图加载失败：地图文件不存在」 | 从非解包目录运行且未指定 `--map` → 在解包目录内运行，或用 `--map /绝对路径/地图文件` |
| 加载自定义地图报错 | 地图不合规（行宽不一/非法字符/豆子不可达/鬼屋无门）→ 按 4.4 格式修正 |
| 游戏画面花屏或退出后终端异常 | 属已知兼容问题 → 直接 Ctrl+C 后运行 `reset` 恢复终端；本版本经 10 次连测退出干净 |
| 想加快/放慢游戏 | `--speed 2.0` 极速 / `--speed 0.5` 慢速演示 |
| 想少几只幽灵 | `--ghosts 2` 或 `--ghosts 3` |

## 6. 卸载

```bash
# 本游戏无系统级安装、无持久化数据（不做最高分存档），删除解包目录即完成卸载：
rm -rf pacman/            # 解包目录
rm pacman-v1.0.0.tar.gz   # （可选）产品包
```
无需卸载任何 pip 包（零依赖）；极简发行版若曾安装 `python3-curses`，可 `sudo apt remove python3-curses`（不影响其他程序时）。
