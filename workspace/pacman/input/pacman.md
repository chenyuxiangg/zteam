# 需求：Linux 终端版吃豆人游戏（人机对战，Python，可使用第三方库）

**投放时间**：2026-08-09
**来源**：Telegram 用户直接投放
**项目**：pacman（用户确认）

## 需求描述

开发一个运行于 **Linux 终端**的吃豆人（Pac-Man）游戏（人机对战），使用 Python 实现。**允许使用第三方库**（与 snake-linux/tetris "从零不依赖框架" 的约束不同；与 gomoku 允许第三方库的约束一致）。

## 期望要点（供分析师展开）

- **对弈模式**：单人对战 AI 控制的幽灵（人机对战），不要求联机双人对战
- **AI 能力**：4 只（或可配）幽灵，每只采用不同追逐/逃跑策略（如 Blinky 直线追击、Pinky 预判拦截、Inky 协同围堵、Clyde 随机/撤退）；具体算法由分析师细化建议（BFS/A*、状态机、行为切换）
- **地图/迷宫**：标准吃豆人迷宫（22×19 或类似规格，可缩放），由分析师给出建议（硬编码 / 从字符串加载 / 自动生成）
- **核心玩法**：玩家吃豆子得分、吃能量豆后幽灵可被反击（限时）、全部豆子吃完过关、撞到幽灵扣命/结束
- **可选第三方库方向**（供分析师参考，不强制）：`numpy`（地图高效表示）、`curses` 或 `prompt_toolkit`/`rich`（终端渲染）、AI 算法无标准库选型——分析师自由选择
- **UX**：终端渲染迷宫（区分墙/通道/豆子/能量豆/玩家/幽灵）+ 实时分数/剩余命/状态（普通/能量暴走）；玩家方向控制（方向键或 WASD）
- **退出干净**：恢复终端原始状态，Ctrl+C 安全中断
- **交付 README**：运行方式、依赖安装（pip）、键位说明、AI 策略说明、配置选项

## 验收标准（待评审确认）

- Linux 终端可玩，渲染清晰、方向控制流畅
- 4 只幽灵采用差异化 AI（不能 4 只全一样）
- 胜负/过关/吃能量豆反击判定正确
- 代码职责分离、README 可让用户在干净 Linux 环境跑通
